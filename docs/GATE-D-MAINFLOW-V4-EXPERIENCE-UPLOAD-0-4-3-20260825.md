## 9. 2026-08-25 真机动效缺陷

- 用户在手机进入 `0.4.3` 后确认：户外风声可听见，但草坡、人物、猫、星与花整体被读成静态。
- 本地 390×844 长时采样确认视觉时钟和图层值均在更新；这不是 Cocos 停帧。开场风约在 `0.7–4.75s`，当前持久调度的第一阵后续风约在 `32.18s`，人物／猫呼吸仅约 `0.4% / 0.3%`，手机正常倍率下等同看不见。
- r3 Web smoke 的户外证据采样时间过早，没有录制 10–35 秒正常倍率视频，因此原“上传后 P1=0”不覆盖本缺陷。
- 手机可见动效子项现为 `FAIL / P1`；`0.4.3` 不得提审或发布，也不得继续作为动效 PASS 证据。
