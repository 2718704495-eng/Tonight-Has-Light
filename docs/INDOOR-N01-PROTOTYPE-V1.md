## 2. 样片的唯一用途

1. 使用一个与正式工程隔离的本地浏览器页面，验证“整屋早已明亮”与“壶盖轻响”是否组成温暖、不像任务的到家体验。
2. 当前批准 PNG 默认只在该本地、可丢弃样片中作为整幅视觉底图；最新一次性例外允许压缩衍生图与预裁片进入 `gate-d-mainflow-v4-phone-preview-dev-r2` 的隔离分包、开发版本 `0.4.2` 及由用户设置的对应体验版。除该唯一例外外，不得复制到 `cocos-project/assets/`、其他 Cocos／微信构建、正式素材目录或发布产物。
3. 样片目录、页面标题和资产清单必须标记 `prototype-only / disposable / not-for-build`，避免后续任务误当正式资产。
4. 正式室内母版仍为 `BLOCKED`；人物、猫、房间、灯、饭菜、壶、杯和关键互动物仍需原创、可编辑、分层重绘及第二次用户批准。

## 3. 已锁定的可见与互动合同

### 3.1 进入与静置

- 首帧直接呈现 `FORMAL-UI-V1.2-A` 的明亮暖家；不叠加暗屋、黑角、整屋亮灯表演、整屏橙色滤镜或奖励式闪光。
- 页面不显示箭头、高亮圈、任务文案、进度条或倒计时。
- 进入后 `10s` 没有操作，只淡入一句环境短句：“壶里的水，正轻轻响着。”它不自动完成核心互动，不催促点击，并自行淡出。

### 3.2 壶盖轻响

- 水壶、壶盖与蒸汽上方共用一个宽松、透明的点击区；在 `390×844` 逻辑画布中目标约 `120×112px`，但不显示可见热区边框。
- 鼠标、单指轻触均能完成；提供键盘等价路径只用于浏览器可访问性与 QA，不新增可见 UI。
- 首次有效轻触后，一缕蒸汽变为三缕，壶盖做一次很轻的回应，约 `600ms` 内记为核心完成。
- 互动必须幂等：连续点击不叠加蒸汽、壶盖运动、完成事件或后续小剧场。点偏没有失败、红字、震动或重来。

### 3.3 杯子小剧场与收尾

1. 壶的回应完成后，人物拿起桌边倒扣的备用杯，停顿约 `0.8s`。
2. 猫先闻一下，再用前爪轻碰一次；猫保持普通家猫行为，不直立、不操作器物、不替用户完成。
3. 用户可轻触杯子提前继续；`4s` 不操作时，人物也会自然发现并把杯子翻正。
4. 人物倒水后出现收尾句：“水热了。你也先缓一会儿。”

杯子小剧场是壶盖核心完成后的轻反馈，不是第二个任务；不点杯子也能完整看到收尾。

### 3.4 减少动态与静音等价

- 样片必须响应浏览器 `prefers-reduced-motion`；可增加仅供 QA 使用的本地开关，但不得变成正式产品 UI 决定。
- 减动时不播放壶盖位移、杯子旋转、人物或猫的位移动画；使用两档静态状态的 opacity／brightness 交叉淡化，每次不超过 `200ms`。
- 静音时仍依靠蒸汽数量、杯子状态和短句理解全部因果。为让用户在样片里感受“壶盖轻响”，允许浏览器运行时临时合成低音量的壶盖、蒸汽与杯子声；不加载或生成音频文件，不播放音乐或室内环境音，也不表示正式触碰音效已经获批。既有户外风声的批准不自动扩展到室内样片。

## 4. 允许的工程性叠加

- 在不修改底图像素的前提下，可使用局部 HTML／CSS／SVG 叠层表达蒸汽两档、壶盖轻回应、倒扣／正放杯、猫轻碰和文案。
- 叠层必须仅作样片验证，不得输出为 Cocos Sprite、Atlas、Prefab 或微信资产。
- 缩放或安全区调整不得给底图叠加暗色遮罩、冷色调色或过曝补光；在 `360×800`、`390×844`、`430×932` 中应保留人物、猫、壶、杯、饭桌和窗外冷夜的完整语义。

## 5. 明确未批准

本次批准不包含：

- 当前 PNG 或任何派生切片进入正式 Cocos 工程、审核版或线上版；唯一例外是 `gate-d-mainflow-v4-phone-preview-dev-r2` 的可丢弃开发预览、开发版本 `0.4.2` 与由用户设置的对应体验版分包。
- 除 `gate-d-mainflow-v4-phone-preview-dev-r2`／开发版本 `0.4.2` 以外的新 Cocos 候选或微信包；仍未批准由主任务设置体验版、提交审核或发布。
- 任何音乐方向、音乐资产、正式触碰音效、室内环境音或最终混音。
- 当前样片自动升格为正式状态机、存档契约、五夜模板或第二至第五夜产能。
- 额外远程部署、再次上传、Git 提交、GitHub 推送或对任何第三方资源的修改。

## 6. 样片放行证据

样片只能在以下证据齐备后记为 `PASS`：

1. 唯一样片 ID、本地启动方式、文件清单与 SHA-256 索引。
2. `390×844` 首帧、壶盖完成态、杯子倒扣态、翻正收尾态四张原始截图，且底图未被压暗、滤色或重构。
3. 零操作 `10s` 记录，证明只出现环境短句，不出现任务引导或自动完成。
4. 点击／触摸、快速重复输入、杯子提前轻触和 `4s` 零操作自然继续的可复查记录。
5. 减动录屏或时间轨，证明全部 transform 动画为 `0`，单次交叉淡化不超过 `200ms`。
6. `360×800`、`390×844`、`430×932` 原始截图；无裁字、无热区漂移，点击目标不小于 `44×44px`。
7. 浏览器 console error 为 `0`；本样片没有音频资产加载、没有远程资源请求，也没有写入 Cocos 或微信包。

本地浏览器样片已实现于 `prototype/indoor-n01-v1/`。上述机器证据、原始截图和 SHA-256 索引已冻结在 `prototype/indoor-n01-v1/evidence/` 与 `prototype/indoor-n01-v1/HASHES.sha256`，本地浏览器检查记为 `PASS`；用户已确认暖屋整体设计感 `PASS`，但真实节奏和轻响音量仍为 `BLOCKED`。这不改变正式 Gate B2、Gate C、Gate D 或 Gate E 的既有状态，也不构成任何 Cocos／微信资产批准。
