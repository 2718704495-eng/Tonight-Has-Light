# FORMAL-OUTDOOR-ART-PILOT-V1-B 批准记录

> 日期：2026-08-29  
> 用户原话：`批准 B：AI 辅助正式分层例外`  
> 当前状态：`ALIGNED / FORMAL ART BLOCKED / NO COCOS / NO BUILD / NO WECHAT / NO GIT`

## 1. 批准内容

用户批准把原“ImageGen 只能用于探索”的规则收窄修改为一次、可审计的正式资产生产例外：允许 AI 辅助生成、修正和分离 `root_night_slope_v1` 草坡入口单帧样板的正式像素。

这项例外的目的不是把现有探索图直接切片入包，而是在已批准的 B 夜漫画视觉合同下重新制作一份高分辨率正式候选，并把其运行时组成拆成可编辑、可追溯的分层 PNG 与开放源包。

## 2. 精确范围

- 候选版本：`FORMAL-OUTDOOR-ART-PILOT-V1-B`。
- 首个候选 ID：`formal-outdoor-art-pilot-v1-b-r1`。
- 只制作一张 `390×844` 逻辑母版：`root_night_slope_v1` 草坡入口 clean plate。
- 允许同时制作与该母版配套的独立“画中邀请”排版预览、安全区／热区标注和分层合成证据。
- 正式源画布为 `780×1688`；运行时导出按 `390×844` 逻辑坐标登记。
- UI 中文、热区、Logo、设置、流星和结尾文案不烘焙进草坡入口插画。

## 3. AI 辅助例外的定义

本次允许：

1. 以已批准 B 风格图和 R2 网页为构图、光色、材质与情绪参考，生成一张新的正式候选母版。
2. 用图像编辑／局部重生成修正人物、普通家猫、银河、草坡、小屋、花和遮挡区域。
3. 从同一获批母版建立透明分层、遮挡后的 clean plate、straight-alpha PNG、OpenRaster 源包和 manifest。
4. 对生成过程、提示词、输入参考、原始输出、人工／程序修改、导出版本和 SHA-256 做完整登记。

本次不允许：

- 直接把 `star-branch-contact-sheet-r3.png`、`b01-settle-reference-r1.png`、旧 B01 formal pilot、`0.4.7` 或任何历史微信包中的像素改名为正式资产。
- 使用现成 IP、品牌、真人肖像、艺术家姓名或“完全模仿某位艺术家”的提示词。
- 用自动描摹、上采样或仅切片来伪称原创分层制作。
- 在单帧样板未经用户可见批准前扩产其他 15 幅、流星正式资产或室内正式资产。

## 4. 保持不变的可见合同

- 深靛有限色、大块明暗、成熟干笔漫画墨线、克制网点与细纸纹。
- 普通成人背影在左、普通家猫在右；共同仰望，不公开性别、姓名或关系。
- 普通深蓝星空、一条宽淡且有暗裂／断口的自然银河、8–10 颗主星。
- 右侧中景小屋与稳定暖门、恰好两朵更弱的微光小花。
- 天空第一、人物与猫第二、暖门第三；不出现任务地图、霓虹极光、满屏粒子或奖励光。
- 画中邀请是独立 UI 层，约 1.5 秒后低权重出现，不改变 clean plate。

## 5. 权限边界

本批准只允许 Gate B 单帧正式分层样板的设计与本地制作。它不批准：

- Cocos 源码、Prefab、Scene、Asset Bundle 或运行时接线；
- Cocos／微信构建、preview、upload、体验版设置、提审或发布；
- Git 提交、推送或远程资源修改；
- 自动扩展“吹吹风”“回家”“看星空”其他页面。

上述动作均需后续 Gate 与新的明确授权。
