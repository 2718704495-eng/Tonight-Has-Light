用户同时确认希望场景具有“微微晃动”的动态效果。项目解释并锁定为局部分层动态，而不是整屏、相机或银河一起摇晃。

## 获批范围

- 首次触碰听见环境风时，同步触发一条完整视觉风链；已有风链运行时不叠加。
- 开场或首触风结束后 `8–12s` 内出现下一阵风，后续 `9–14s` 非固定出现。
- 风始终按远草→近草→人物发梢／衣角→猫耳／尾尖传递。
- 峰值采用提案 A 表：`2.2° / 3.6° / 3.8° / 4.2° / 4.5° / 6.5°`；人物／猫呼吸为 `0.6% / 0.7%`。
- 仅增强既有六个局部通道与呼吸；局部 overlay 不超过 `0.40`。

## 明确不在批准范围

- 不允许整张画面、相机、银河、小屋或地平线共同摇晃。
- 不改变 V7 角色、构图、材质、配色、夜空、门光、两朵花、室内暖屋和收尾 UI。
- 不新增粒子、Bloom、3D 灯光、镜头推进、按钮、教程或任务提示。
- 减少动态模式仍关闭所有 transform、草浪、云位移与视差，只允许≤`200ms`亮度／交叉淡化。
- 本批准允许本地源码实现、自动验证、本地 Web/微信构建和可见证据制作；不允许上传、设置体验版、提审、发布、Git 提交或推送。
