# Gate C 风链可读性 A/B 提案 V1

> 提案 ID：`GC-WIND-AB-V1`  
> 日期：2026-08-21  
> 状态：`A APPROVED`；用户于 2026-08-24 委派主任务继续推进并优先关闭风链，主任务采用最小变化的 A；B 继续 `BLOCKED`  
> 范围：只调整一阵风的局部振幅、峰值间距和 overlay 上限，不改变 V7 静态样式

## 1. 为什么需要改

独立 QA 对 r5 的 GC-06 判定为 `FAIL / P1`：时间轴与因果顺序正确，但在 390×844 正常倍率 MP4 中，远草、人物发梢/衣角、猫耳等阶段不能稳定裸眼辨认；完整链条主要依靠放大差分或调试值才能确认。

当前峰值时间中，人物衣角为 2850ms、猫耳为 2900ms，仅相差 50ms，容易在正常观看中合并成一次局部抖动。当前最大旋转角依次为 `1.2° / 2.0° / 1.2° / 1.6° / 1.1° / 2.2°`，风层透明度上限为 `0.18`。

## 2. 研究结论与边界

- Apple 的 Motion 指南要求动效有明确目的、服务体验且不抢过内容，并要求为不希望体验动态的人提供可关闭路径：<https://developer.apple.com/design/human-interface-guidelines/motion>
- Apple 的 Accessibility 指南建议在 Reduce Motion 下减少自动、重复、缩放和外围位移，必要时用淡变替代位置变化：<https://developer.apple.com/design/human-interface-guidelines/accessibility>
- W3C WCAG 2.3.3 要求非必要的交互动效能够被关闭，系统的减少动态偏好应被尊重：<https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions>
- Cocos Creator 3.8 支持对 transform、rotation、scale、color 等属性做可控时间插值；本项目继续使用可测试的时间轴采样，不引入新粒子或镜头系统：<https://docs.cocos.com/creator/3.8/manual/en/tween/>

上述来源没有规定本项目应使用多少度或多少毫秒。以下数值是根据 r5 实测失败形成的工程假设，必须通过 A/B 正常倍率视频与用户观察验证，不能写成通用设计定律。

## 3. A/B 方案

### A：清风可读（推荐）

目标是让因果链可辨，但仍像一阵凉风，而不是角色表演。

| 通道 | 峰值时间 | 最大旋转角 |
|---|---:|---:|
| 远草 | 1450ms | 1.5° |
| 近草 | 2050ms | 2.5° |
| 人物发梢 | 2650ms | 1.5° |
| 人物衣角 | 3150ms | 2.0° |
| 猫耳 | 3600ms | 1.4° |
| 猫尾尖 | 4150ms | 2.8° |

- 相邻峰值间隔约 450–600ms；整阵风在约 5.0 秒前回到静态。
- 风 overlay 上限由 `0.18` 提到 `0.22`。
- 呼吸、云、主星、花、门、镜头和静态首尾帧完全不变。

### B：风感明显（未批准，不得实现）

用于判断 A 是否仍然太轻；不能默认进入正式候选。

| 通道 | 峰值时间 | 最大旋转角 |
|---|---:|---:|
| 远草 | 1400ms | 1.8° |
| 近草 | 2050ms | 3.0° |
| 人物发梢 | 2700ms | 1.8° |
| 人物衣角 | 3250ms | 2.4° |
| 猫耳 | 3800ms | 1.7° |
| 猫尾尖 | 4400ms | 3.3° |

- 相邻峰值间隔约 550–650ms；整阵风在约 5.4 秒前回到静态。
- 风 overlay 上限为 `0.26`。
- 其余保持项与 A 相同。

## 4. 明确保持不变

- 不改人物、猫、银河、星点数量、色调、小屋、道路、两朵花、材质和构图。
- 不加镜头摇动、视差、Bloom、粒子、动态模糊、全局亮度呼吸或第二阵风。
- 不改变四颗主星、两花、人物/猫呼吸的既有节奏。
- t=0、t=9.8s、减少动态静态态必须继续与 V7 零差。
- 减少动态模式下所有位移、旋转、缩放、草浪和视差继续为 0；只保留原有静态画面，不因 A/B 增强。

## 5. 给开发窗口的已批准提示词

> 基于获批 V7 与 r5 可复用工程边界，生成唯一新候选 `gate-c-v7-20260824-41b0b7b1-wind-a-audio-v1`。只实现本提案 A：只能修改 `OUTDOOR_GATE_C_WIND_CUES`、对应最大旋转角和风 overlay 上限；严格使用第 3 节 A 数值。禁止实现 B，禁止更换或重绘任何资产，禁止改变银河、角色、猫、花、门、色彩、构图、呼吸、星光和镜头。输出 9.6–10.0 秒正常倍率 MP4、t0/mid/tail/reduced 截图、逐通道峰值表和 console/performance 报告；候选不得自动标记 Gate C PASS，必须由独立 QA 从 GC-01 到 GC-13 全量复验。

## 6. A/B 选择门槛

- 5 名未参与实现的人正常倍率观看；至少 4/5 能按“草先动、人物随后、猫最后”复述，不看调试值或放大差分。
- 至少 4/5 认为是“凉风/舒服/自然”，不得有 2 人认为“角色在抖、风太大或画面焦躁”。
- 天空仍是第一焦点，门不主动催促；首尾和减动静态态无样式漂移。
- A 达标则采用 A；只有 A 未达标且 B 达标时才考虑 B。两版都不达标时返回动效设计，不继续放大。

## 7. 已分离验证的音频

风声不与 A/B 视觉强度捆绑批准。用户已批准 Freesound CC0 候选 `Grass Blowing in Wind — floft` 的处理试听；唯一 `audio-proof-v1` 已验证 26 秒 OGG 的首触前静音、首触后渐入、静音恢复、浏览器模拟前后台和单实例循环。新候选只消费该已批准文件，不改变音色、音量合同或音乐状态：<https://freesound.org/people/floft/sounds/205109/>
