# 包体、性能、声音与无障碍验证

> 版本：v1.2（户外 V7 / Gate C 路径优先）  
> 适用：Gate C 高保真原型与 Gate D 微信小游戏构建  
> 声明：本项目以 WCAG 2.2 AA 的对比、非颜色信号、单指替代等原则作为设计基线，但不在未验证 Canvas 辅助技术暴露的情况下宣称“完整符合 WCAG AA”。

### 2.2 项目内部保守预算

| 项目 | 预算 | 超限行为 |
|---|---:|---|
| 主包（不含分包和 remote） | ≤ 4 MiB | 构建失败，必须移出非启动必需资源或裁剪引擎模块 |
| 上传包总计（主包＋分包） | ≤ 20 MiB | 构建失败，优先优化纹理/音频，不删除无障碍状态 |
| 远程资源 | 单独报告 | 未明确缓存、失败降级和版本策略时不启用 |

`MiB = 1024×1024 bytes`。脚本执行：

```bash
node scripts/audit-package.mjs /absolute/path/to/wechatgame-build
```

必须保存：主包字节数、每个分包字节数、上传总字节数、remote 字节数、体积前 20 文件。脚本通过只表示满足项目内部预算，不代替开发者工具上传预检。

### 2.3 资源收敛顺序

1. 删除未引用和重复导出资源。
2. 裁掉透明空边，按场景/夜晚合图，禁止跨五夜巨型图集。
3. 纸纹和主要阴影静态烘焙；禁用全屏实时噪点、实时模糊和多层加色光罩。
4. 按实际屏幕占比导出纹理，不将每个全屏层无差别导出 DPR=3。
5. 长音乐和环境循环与短音效分开压缩/加载策略，在真机复听循环接缝。
6. 最后才考虑远程资源；远程化不能代替首夜可用和弱网降级。

## 4. 性能采样协议

### 4.1 当前 Gate C/D 户外固定路径

1. 结束微信小游戏进程，重新打开，记为冷启动。
2. 从点击入口到首个可交互帧，记录时间与是否白屏。
3. 前 20 秒不操作，记录是否出现标题、按钮、提示、强制进度或空白；观察弧形星河、角色共同仰望、主星、薄云、两朵花与一次自然风。
4. 在全程静音下复看一轮，确认仍能从远草→近草→人物发梢/衣角→猫耳/尾尖辨认统一风向；再首次触碰，记录环境风响应与音乐 2–3 秒渐入。
5. 各执行 10 次点花、点天空、慢滑草地和点门；记录命中率、首次像素反馈、快速乱划是否叠加强风、门是否从第一秒可用且不显得催促。
6. 验证户外互动不写入五夜完成/解锁；进门中途切后台后回到安全节点，不重复开场、不重复触发室内 `OPEN_NIGHT`。
7. 户外持续停留到 10 分钟；第 6 分钟切后台 10 秒再回来，第 8 分钟切静音再恢复；记录节点、纹理、监听器和音轨是否增长或叠加。
8. 在减少动态模式重复步骤 3–5，确认草浪、位移、视差和镜头推进关闭，静态态仍完整可理解。
9. 停止采样，保存性能面板、录屏与问题记录；每台设备完成 3 轮独立冷启动。

### 4.2 进入室内后的扩展路径

本路径只能验证用户主动点门后的室内阶段，不能单独判定当前户外 Gate C/D 通过。

1. 进入室内后选择 5 分钟，完成暖光到水壶、反杯小剧场、窗雾、围巾和收尾。
2. 回到房间继续停留，并验证声音、设置、暂停、前后台恢复与分享预览。
3. 记录室内阶段的性能与内存；与户外进入/释放前后的资源数量交叉检查。

### 4.3 记录字段

| 轮次 | 首可交互 ms | 平均 FPS | P50 FPS | P95 帧耗时 ms | >100ms 长帧数 | 输入 P95 ms | 预载后最长冻结 ms | 内存峰值 MB | 10min 增量 MB | 单调增长 | 音频异常 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---|---|
| 1 | | | | | | | | | | | | |
| 2 | | | | | | | | | | | | |
| 3 | | | | | | | | | | | | |

输入延迟从触摸事件时间到第一个可见像素反馈开始计算，至少采集 30 次触摸。内存增量使用进入稳定房间 60 秒后的数值与第 10 分钟数值之差，不主动强制 GC。“单调增长”指三轮内的同一路径都持续上升且无稳定回落；即使增量未超 20MB 也必须调查。

### 4.4 通过线

- A2/A3/I1/I2 三轮平均 FPS 的平均值≥55，无连续输入失效。
- A1 降级后三轮平均 FPS 的平均值≥30。
- 输入反应 P95≤100ms；预载完成后无 >250ms 的可感知冻结。
- 每轮 10 分钟内存增量≤20MB，且不持续单调增长。
- 转场无白屏、纹理闪烁、角色跳位和音轨断裂/叠加。

单轮异常不直接删除；先标记可复现条件。只有被证明为工具采集故障的轮次才可重测替换，原记录仍保留。

## 5. 声音验证

- [ ] 用户首次主动触碰前不自动播放；触碰后环境风先响应、音乐在 2–3 秒内渐入，无突然鼓点/高频。
- [ ] 音乐、房间声、触碰反馈可分别关闭，下次打开恢复本地设置。
- [ ] 每条长循环连续播放 10 分钟，头戴耳机和手机外放都无明显接缝、爆音、底噪跳变。
- [ ] 可见触碰到对应短音效的感知起点差≤50ms；静音下有同等明确的微光/物件反馈。
- [ ] 切后台、锁屏/解锁、耳机插拔、来电/系统打断后不叠播，不补播过时短音效。
- [ ] iOS 和 Android 分别验证静音键/媒体音量、后台恢复与多音效并发。

## 6. 无障碍与包容性基线

### 6.1 可感知

- **文本对比**：普通文字≥4.5:1；大字和关键 UI 图形/边界≥3:1。以最终合成后的实际背景颜色测量，不只用设计 Token 标称值。
- **非颜色信号**：所有开关同时用开/关位置、形状和文字表示；核心物件用光晕＋角色视线＋超时文字，不只换色。
- **静音等价**：水壶升温、杯子扶正、加载失败、夜晚完成都有可见变化，声音不是唯一提示。
- **暗光**：在约 20% OLED 亮度下角色轮廓、核心物件与文字仍可辨；在约 60% LCD 亮度下琥珀光内不丢纹理。

### 6.2 可操作

- **触控区**：所有可点目标≥44×44 逻辑像素，相邻关键目标的热区边缘至少相距 8px；可见图标可小于热区，但热区不得互相重叠。
- **复杂手势替代**：暖光、毯子、擦雾和开门均有单击/分步点选方式；第四夜的三盏多余小灯使用放大热区的直接轻触。不要求精确路径、双指、摇一摇或持续高频点击。
- **宽松容错**：核心吸附半径 28px，松手过早保留当前进度，误触环境物不覆盖核心动作。
- **随时离开**：暂停内有“结束今晚”；无连续弹窗、无二次情绪挽留、无退出惩罚。

### 6.3 大字与响应式

- 大字模式将叙事和控件文字放大到默认的 120%，最小正文不低于 17px 逻辑尺寸；不通过缩小行高或压窄字形塞回原容器。
- 360、390、430 逻辑像素宽的实字截图必须覆盖：停留时长、操作提示、最长收尾文案、设置、加载失败和分享落地。
- 文字最多两行；需要三行时扩展容器且不遮挡角色脸、核心物件或操作热区。
- 顶部使用运行时安全区/胶囊信息计算，底部动作高于系统手势区；不只按 390×844 整屏等比缩放。

### 6.4 减少动态

开启后固定执行：

- 关闭前景/远景视差、镜头推拉、缩放呼吸和雪花横向漂移。
- 将循环雪、蒸汽、窗帘改为静态关键帧或极慢的不连续淡变。
- 保留 160–240ms 透明度淡入/淡出和必要的状态切换；无大幅移动、旋转或弹性回弹。
- 核心互动进度使用静态状态差和文字确认，不因减少动态丢失因果。

### 6.5 辅助技术能力探针

Cocos/Canvas 节点不得默认被 VoiceOver、TalkBack 或开关控制正确读取。Gate D 必须在当前微信、基础库和 Cocos 3.8.8 输出上执行一次探针：

| 平台 | 辅助技术 | 检查 | 结果/证据 |
|---|---|---|---|
| iOS | VoiceOver | 启动、时长选择、静音、核心互动、结束是否有名称/角色/状态 | |
| Android | TalkBack | 同上，并检查滑动焦点顺序 | |
| iOS/Android | 开关控制/外接键盘 | 是否能到达和激活关键控件 | |

- 若当前平台有官方支持的可访问节点/覆盖方案，优先用它为关键控件提供名称、角色、状态和操作顺序，不自建与实际画面脱节的隐形热区。
- 若没有可靠的官方路径，必须在发布风险中明确记录“读屏/开关控制未覆盖”，不宣称完整 WCAG AA 或完整读屏支持。
- 视觉、静音、减少动态、大字和拖拽替代的已通过结果必须与此平台限制分开表达。

## 7. 中断、存档与弱网

| 场景 | 预期 | 验证点 |
|---|---|---|
| 拖拽中切后台 | 保存最近安全节点，回来后重开当前动作 | 无瞬移、无自动完成、无音效补播 |
| 核心完成后小剧场中切后台 | 完成标记已保留，回到安全片段 | 不重复解锁，不叠播 |
| 主动退出未完成核心 | 本夜未完成，下次从夜晚开始 | 无惩罚、无挽留弹窗 |
| 分包加载失败 | 保留基础房间，可重试/取消 | 不丢设置和已完成夜晚 |
| 分享取消/失败 | 回收尾画面 | 完成标记不变，不显示奖励损失 |
| 存档 JSON 截断/未知版本 | 保留可验证的设置，重建进度 | 显示友好提示，无技术堆栈 |
