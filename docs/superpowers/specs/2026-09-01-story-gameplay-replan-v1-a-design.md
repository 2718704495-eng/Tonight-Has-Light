## 1. 这次要解决什么

`0.4.8` 证明了已批准插画能在手机显示，但它的主要行为是“点击下一张”，流星和吃饭各只有数秒，玩家的选择不会改变后面。因此它只有顺序，没有故事、参与和余韵。

新方案不靠循环拉长时长，也不靠单独的图片、动图或文字撑起体验。每个有效节点必须具备：

```text
前置状态 → 事件或玩家动作 → 世界／角色回应 → 之后仍可看见的后果
```

删掉一个节点后，如果后面毫无改变，它就不算故事节点。

## 2. 展示语法：五层只做一件事

| 层 | 职责 | 禁止 |
|---|---|---|
| 全幅插画 | 建立地点、角色、冷暖和情绪 | 靠整图持续摇晃假装动画 |
| 局部动态 | 说明风、云、蒸汽、衣角、猫耳发生了什么 | 满屏粒子、Bloom、无因果的呼吸缩放 |
| 玩家动作 | 让玩家参与观察和生活动作 | 连续点击任意位置翻页 |
| 角色／物件回应 | 把动作变成故事，并留下后续状态 | 奖励闪光、成功字样、结算感 |
| 声音与文字 | 声音补材质，文字补意义 | 用文字解释画面没有表达的因果 |

### 文字入画 R1

用户已指出：评审页右侧有文字时效果好，但真正手机里只有左侧画面，会显得单调。因此文字必须成为游戏内叙事层，不依赖外部说明。

每幕在手机内显示：

1. 一个低权重地点或时刻，如“今夜 · 草坡”。
2. 一个短标题，如“灯还亮着”。
3. 两到三行情境旁白，说明此刻值得留意的人、物或变化。
4. 事件发生后，只改写正文，不叠加新弹窗。

户外使用深蓝半透明墨片，放在中部留白，避开人物、猫和按钮；室内使用浅暖纸，放在墙面留白。文字不超过三行，大字模式为真实 `120%`，不使用 SHRINK。

## 3. 完整可玩竖切片

### 3.1 用户可见流程

```text
夜风草坡
  ├─ 看星空 → 认出一颗星 → 薄云遮住 → 陪云走一段
  │             → 云缝重开，猫靠近 → 一颗流星
  │                                      ├─ 再坐一会儿
  │                                      └─ 回家
  ├─ 让风经过 → 草、衣角和猫回应 → 花瓣／草籽留在衣角
  └─ 回家 → 明亮暖屋 → 放下外衣 → 壶盖轻响
                         → 把热饭端到桌边 → 吃／温水自由顺序
                         → 暖家全景回看 → 留灯／再坐／今晚到这里
```

自然首玩约 3.5–6 分钟；快速直接回家约 90 秒。草坡、流星后和暖家收束均可无限停留。时长来自事件、玩家动作和回应，不靠倒计时、强制等待或循环动画。

### 3.2 十六个故事状态

| # | 状态 | 玩家行为 | 画面／角色回应 | 会留到后面的结果 |
|---|---|---|---|---|
| 01 | `ROOT_STILL` | 零操作停留，也可点天空、草或门 | 主星错峰微亮，人和猫异步呼吸，门稳定 | 草坡安全恢复点 |
| 02 | `WIND_AWAKENS` | 沿草坡慢滑；轻触两次等价 | 远草→近草→衣角→猫耳／尾尖；一颗草籽或花瓣停在衣角 | `windToken=true`，进屋后会出现 |
| 03 | `LOOK_UP` | 点天空 | 从 Root 进入 F1，猫的头轴指向一颗主星 | `mainStarKnown=true` |
| 04 | `EYES_ADJUST` | 在深蓝留白处按住；轻触等价 | F2 银河暗裂和疏密慢慢可辨 | `eyesAdjusted=true` |
| 05 | `STAR_OCCLUDED` | 可零操作观察 | F3 薄云遮住同一颗星，猫耳转向云的方向 | `starOccluded=true` |
| 06 | `FOLLOW_CLOUD` | 顺云慢滑；轻触两次等价 | 玩家不是消灭云，只是陪它走一段 | `followedCloud=true` |
| 07 | `STAR_RETURNS` | 触碰重新出现的星，或安静等待 | F4 主星回来，猫往人这边靠一点 | `catSettled=true` |
| 08 | `WIDE_SKY` | 松开手，也可继续看 | F5 大全景，人和猫很小，远门仍亮 | `stargazeComplete=true` |
| 09 | `METEOR_EVENT` | 无须操作，一次且只一次 | 流星序列，人物肩线、猫耳和草脊同时接到冷白反光 | `meteorOrigin=outside` |
| 10 | `AFTER_METEOR` | “回家”或“再坐一会儿” | 背景仍是完整 F5，流星不重播 | 选择不清空本晚状态 |
| 11 | `DOOR_MATCH_CUT` | 选择回家即成立 | 暖门光展开并让出 H1；不黑屏，不演黑屋开灯 | `indoors=true` |
| 12 | `ARRIVAL_H1` | 外衣拖向挂钩；点挂钩等价 | H1→H2，外衣从身上到墙上，猫从脚边经过 | `coatHung=true`，H3–H5 仍可见 |
| 13 | `KITCHEN_CALL` | 点厨房暖区 | 厨房局部蒸汽先回应，再进 H3 | `kitchenEntered=true` |
| 14 | `COOK_AND_SERVE` | 按住壶盖，再把热饭拖到盘边；均有轻触替代 | 壶盖轻响、蒸汽增加、菜真正进盘，猫远离热源 | `mealServed=true` |
| 15 | `TABLE_RITUAL` | 先吃或先喝，可只做一项 | 食物减少或水线改变，猫根据第一动作做不同回应 | `firstTableAction`、`ate`、`sipped` |
| 16 | `LEAVE_THE_LIGHT` | 留门廊灯／桌边再坐／今晚到这里 | H5 显示外衣、饭桌、猫、风的小痕迹和本轮流星位置 | `lightChoice`；真正的继续或结束出口 |

## 4. 分支不是选项文案，而是后续差异

| 先前选择 | 后面至少两处变化 |
|---|---|
| 先让风经过 | 花瓣／草籽留在衣角；挂外衣时落在门边；H5 桌或门边仍可见 |
| 户外看过流星 | H5 窗面保留很弱的同一星痕；收尾回忆写“在草坡看见流星” |
| 直接回家 | H5 才从窗外看到同一颗流星；不强迫用户先走星空线 |
| 先吃一点 | 浅盘状态改变；猫闻热气后回坐垫；H5 保留食物减少 |
| 先喝温水 | 杯子水线与位置改变；猫抬一下耳朵；H5 保留喝过的杯 |
| 留门廊灯 | 屋内不突然变亮；只把外面能看见的同一盏暖灯稳定保留 |

## 5. 输入、恢复与低压力规则

- 慢滑、长按、拖放和划圈都提供轻触等价；不因手势失败卡住。
- 热区不小于 `44×44px`，相邻热区至少 `8px`。
- 不显示页码、任务、成功、奖励、连续天数、倒计时或完成率。
- 安全恢复点为 Root、F2、F4、流星后、H1、H2、H3、H4、H5。正在拖动时切后台，回来只重开当前动作。
- “再坐一会儿”不清空本轮状态，不重播流星，不自动进入下一夜。
- 用户可从首帧点门直接回家；星空和风均不是必做任务。

## 6. 声音、静音、减少动态和大字

- 首次触碰前数字静音，画面先表达风。首触后户外风先回应，音乐若后续获批准，再于 2–3 秒渐入。
- 户外进屋时，风在约 700ms 内收远，室内环境声接近；不播奖励式音效。
- 壶盖、衣料、陶杯和碗盘只使用一次、轻量、可识别的材质声；避免咀嚼和吞咽 ASMR。
- 静音时，物件状态、角色回应和文字必须完整表达因果。
- 减少动态时关闭草浪、云位移、镜头推拉、暖光扩张和蒸汽位移；使用 `≤180ms` 交叉淡化和静态结果帧。
- 大字模式为真实 `120%`。户外文字片不遮人物和主星；室内使用已批准桌边暖纸规则。
