# FORMAL-PICTUREBOOK-FULLFRAME-V1-A 设计规格

> 日期：2026-08-29  
> 状态：`SPEC APPROVED / BATCH 1 AUTHORIZED / ART PRODUCTION IN PROGRESS / R1 USER VISUAL PASS / NO COCOS / NO BUILD / NO WECHAT / NO GIT`

## 1. 为什么更换资产路线

用户已明确批准：`批准 R1 单帧视觉；改用全幅正式插画页＋独立 UI/流星效果层。`

R1 证明 B 夜漫画方向能够达到可接受的单帧观感，但原 `FORMAL-OUTDOOR-ART-PILOT-V1-B` 要求从同一母版反向生成 20 个真实 straight-alpha 层。首个成年人层探针返回 `853×1844 RGB / hasAlpha=false`，棋盘格和背景被烘焙进像素；继续抽层只会得到伪分层或背景幽灵。因此新路线不再把“逐物件反向拆层”当作正式插画成立的条件。

旧探针失败、禁止自动抠图、色键、隐藏 flatten 与空层兜底的结论继续有效；它们是换路线的原因，不得被改写成旧方案通过。

## 2. 当前决定

新正式路线命名为 `FORMAL-PICTUREBOOK-FULLFRAME-V1-A`：

1. 每一页故事由一张完整、无字、无 UI 的正式全幅插画 clean plate 承载。
2. 中文邀请、提示、触控区、返回与结尾选择属于独立 UI 层，不烘焙进插画。
3. `STARGAZE-SKY-FINALE-V1-A` 的一颗流星属于独立效果层，不烘焙进 F5 clean plate。
4. 第一版不要求把人物、猫、草、房屋、银河等重新反向拆成 20 层，也不得用装饰层冒充它们已经可编辑。
5. 正式全幅页允许以 `ai-assisted-formal-fullframe` 如实登记；这是一项只适用于本绘本页面的有边界例外，不等于生成图可以无审查地进入其他页面、角色资产、Logo、中文、图标或 UI。

## 3. 被保留与被替代的合同

### 保留

- `OUTDOOR-PICTUREBOOK-BRANCH-V1-A` 的三路入口、逐页点击和出口语义。
- `STARGAZE-SKY-FOCUS-V1-A` 的五幅星空镜头。
- `STARGAZE-SKY-FINALE-V1-A` 的 F5 clean plate、单颗流星时间线、固定文案和双出口。
- B 夜漫画：深靛有限色、大块明暗、干笔漫画墨线、克制网点与纸纹。
- 成年人背影＋普通家猫、右侧暖门、两朵弱光花、一条宽淡断口银河、8–10 颗主星。
- `FORMAL-UI-V1.2-A / 灯一直为你亮着` 的明亮暖家语义。
- 资产来源、提示词、人工修改、哈希、相似性检查和逐页用户批准要求。

### 替代

- 新路线替代 `FORMAL-OUTDOOR-ART-PILOT-V1-B` 的“每张必须由 20 个真实语义层重建”要求。
- 全幅 clean plate 不需要透明背景；可以是无 Alpha 的 RGB，也可以是全不透明 RGBA。只有需要透明叠加的独立流星位图效果层必须通过真实 Alpha 检查。
- 旧方案的 ORA、20 层 manifest 和像素级重建不再是全幅页面的 Gate。新 Gate 检查的是单页视觉、连续性、来源、适配、哈希和独立覆盖层边界。

### 禁止复活

- `0.4.7` 自动三拍、旧五幅风页和 V7 水粉风不能作为当前正式绘本的故事感或画风证据。
- 历史探索图、联系表、B01 参考、`0.4.6`／`0.4.7` 像素不得裁切、描摹、上采样、改名或嵌入新正式页。
- 不得把一张完整图藏在底层，再用空层、假透明层或少量装饰层声称“正式分层完成”。

## 4. 正式资产单元

### 4.1 全幅 clean plate

- 源母版：`780×1688`，sRGB，8-bit，无损 PNG。
- 逻辑画布：`390×844`。
- 画面必须完整出血；不得包含中文、伪中文、Logo、水印、页码、按钮、热点标记、流星或调试辅助线。
- 每页是一张独立构图的正式插画，不是从联系表裁出来的一格。
- R1 根页继续使用现有 `ART-OUTDOOR-001` 身份，不改名、不重新生成；详细规格批准后只做状态登记与多尺寸正式导出。
- 后续运行时压缩格式、图集和分包属于 Cocos Gate 决策，本规格不把源母版格式直接等同于微信包格式。

### 4.2 独立 UI 层

独立 UI 至少包括：

- 根页约 `1.5s` 后出现的 `看看星空`、`吹吹风`、`回家`；
- 空白处首次轻触时的一次低权重提示；
- 支线返回或结尾操作；
- 星空终章固定文案与 `回家`／`再坐一会儿` 两个选择；
- 热区、安全区和 QA 标注，但 QA 标注永不进入用户画面。

UI 必须由可编辑中文文本、SVG 或项目自绘 PNG 组成。不得依靠生成图里的文字。根页邀请保持画中低权重，不做卡片、工具栏、选关菜单、奖励按钮或进度 HUD。

触控区不得小于 `44×44px`，相邻热区至少 `8px`；门与天空重叠时门优先，人物／空白提示优先级最低。120% 大字不得 `SHRINK`。

### 4.3 独立流星效果层

- 只绑定 `scene_02_stargaze_shot_005`。
- F5 clean plate 本身必须无流星、无文字。
- 时间线固定为：`0.9s` 净底静置 → `0.8s` 一颗流星 → `0.45s` 尾迹淡去 → `1s` 安静停留 → `180ms` 文案显现。
- 流星从右上向人物与猫上方的开放天空划过，不指向门，不循环，不形成流星雨，不表达愿望、奖励或任务。
- 若使用位图，必须是可验证的 straight-alpha RGBA；若使用 SVG／Shader，源文件和参数必须可编辑、可追溯。
- 减少动态时位移与 transform 为 0，只用一道中性静态流星痕做 `≤180ms` 交叉淡化。

## 6. 连续性硬约束

- 成人始终是普通成年人体态，短发、宽松上衣、长裤、平底鞋；不显露确定脸、姓名、性别或关系。
- 猫始终是普通四足家猫，不穿衣、不站立、不放大成吉祥物；保留自然颈胸、背、后肢、爪、尾根和完整尾巴。
- 根页保持成人左、猫右、小屋和暖门右侧；镜头可变化但不得镜像地点。
- 暖门是唯一明显暖源，花光更弱；门不闪、不脉冲、不变成奖品。
- 户外仅一条宽淡、松散、有暗纹和断口的自然银河；无月亮、第二银河、极光、星座线、Bloom 或额外流星。
- 星空 F3／F4 是锁定机位，只有同一薄云推进并重新露出同一主星。
- 吹风 F2–F5 使用同一片草叶，风向和因果保持远草→近草→发梢／衣角→猫耳／尾尖。
- 回家 F4 才打开门；F5 不增加派对、群像、彩带或黑角，不重新设计已批准的明亮暖家。

## 7. 页面转场

- 普通翻页：预加载双全幅页面，使用 `260ms ease-in-out` 透明度交叉淡变。
- 进入支线或返回根页：`320ms ease-in-out` 透明度交叉淡变。
- 转场中不得出现黑帧、白闪、空帧、拉伸、整屏缩放或相机摇晃；点击只触发一次，不叠加队列。
- 减少动态：所有位移、视差、缩放和推进为 0，统一使用 `150ms` 透明度交叉淡变。
- 此处只冻结体验合同；Cocos 双 Sprite、预载和资源释放属于后续实现 Gate。

## 8. 适配与安全区

- 基准：`390×844`。
- 必须交付：`360×800`、`390×844`、`430×932`、`430×844-pressure` 与 `195×422` 缩略图。
- 使用等比 `SHOW_ALL`，安全边颜色固定为 `#06265F`；不得拉伸或重新构图。
- 成人、猫、门、两朵花与银河主形在适用的全景页中不得被裁掉；特写页只能按分镜有意省略地景，不得用适配裁切制造省略。
- 顶部胶囊、状态栏与底部手势区 overlay 不得覆盖关键视觉或操作。

## 9. 生产批次

详细规格获用户确认后，仍不一次生成全部 15 张新页面。

### Batch 0：已批准根页登记

- `root_night_slope_v1`
- 使用已批准 R1 母版；不重新生成，不消耗定向修图机会。
- 目标：把它从“分层失败的单帧样板”迁移成新路线下的“全幅正式候选”，完成来源、导出和新合同检查。

### Batch 1：最多三张的正式证明批

1. `root_night_slope_v1`：全局风格、角色与入口锚点。
2. `scene_02_stargaze_shot_005`：天空主体、F5 clean plate 与独立流星边界。
3. `scene_01_home_shot_005`：户外冷静到室内明亮暖家的情绪落点。

三张逐张制作、逐张审查，不允许“一次生成三张后一起补救”。任一张 `FAIL` 即停止该批，不进入第二批。

### 后续批次

只有 Batch 1 三张同一版本通过负责人、独立只读审查和用户可见批准，才另写实施计划，按连续性风险分批扩展其余页面。`scene_03_breeze` 需作为一组控制同一草叶和动作连续性，不能拆散后无检查地量产。

## 10. 每页来源与资产记录

每张正式页面至少记录：

- 稳定资产 ID、页面 ID、候选版本和状态；
- `source_property=ai-assisted-formal-fullframe`；
- 完整提示词、生成工具／模型、日期、原始输出与 SHA-256；
- 归一脚本、人工修正说明、正式母版与 SHA-256；
- 参考材料及其权利边界；默认第三方素材为 0；
- 390、195 和四种 SHOW_ALL 证据；
- 人物、猫、小屋、银河、UI 字形／图标和流星形态的相似性检查；
- 用户批准的具体文件、版本、SHA-256 和批准范围。

外部素材若非 0，必须补作者、来源、许可快照、商用与修改权限。提示词禁止现成 IP、品牌、真人肖像、在世艺术家姓名和“完全仿照某作品”。

建议稳定 ID：

- 根页保留 `ART-OUTDOOR-001`；
- 回家页：`ART-PBOOK-HOME-001..005`；
- 看星空页：`ART-PBOOK-STAR-001..005`；
- 吹风页：`ART-PBOOK-BREEZE-001..005`；
- UI 合同：`UI-PBOOK-HUB-001`、`UI-PBOOK-FINALE-001`；
- 流星效果：`FX-PBOOK-METEOR-001`。

## 11. Gate B 二元验收

每张只允许 `PASS`、`FAIL` 或证据缺失时 `BLOCKED`。任一 P0／P1 视觉问题停止扩产。

1. 390 与 195 下第一视觉焦点符合本页分镜；根页必须依次读成天空、共同看天的一人一猫、右侧安静暖门。
2. 无中文、伪中文、Logo、水印、页码、按钮、任务标记或烘焙流星。
3. 成年人的肩背、骨盆、腿和衣物连接可信，不像儿童或半身纸片。
4. 猫的颈胸、背、后肢、爪、尾根可信，不拟人、不吉祥物化。
5. 星空只有一条宽淡断口银河；两朵花微弱，不像收集物或路标。
6. 相邻页面发生清楚的事件、回应和结果，不是同图轻微换色或无意义换 pose。
7. UI／流星覆盖层不改写 clean plate，也不把门或选择做成任务按钮。
8. 360／390／430、120% 大字、减少动态和静音状态下仍能理解入口与出口因果。
9. 来源、提示词、人工修改、相似性检查、哈希和资产登记完整。
10. 用户批准的是同一文件和同一 SHA-256；不得用旧探索图、联系表或历史微信包替代。

## 12. 性能与包体前置预算

- 本 Gate 只批准源资产合同，不承诺把 16 张 `780×1688` PNG 原样放进微信包。
- Batch 1 完成后必须先测实际 PNG／WebP／纹理压缩大小、峰值解码内存、双页转场峰值和分包策略，再决定后续产量。
- 运行时同一时刻原则上只保留当前页、下一页和必要覆盖层；不得常驻解码全部 16 张。
- 不使用满屏实时噪声、Bloom、大量粒子或 3D 灯光补救插画。
