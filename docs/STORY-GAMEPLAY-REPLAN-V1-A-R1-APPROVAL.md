## 2. 批准范围

1. `0.4.8` 的“逐图点击、约二十秒结束”不再是当前产品主线；新的第一晚必须是一个约 3–6 分钟、可停留、可直接回家且有后续余韵的完整闭环。
2. 正式故事合同采用 16 个状态：夜风草坡、风留下痕迹、抬头、眼睛适应、云遮星、陪云走、星回来、大全景、一次流星、流星后选择、门光匹配切、归家、厨房回应、做饭端菜、饭桌仪式、留灯收束。
3. 每个有效节点必须包含“前置状态 → 事件或玩家动作 → 世界／角色回应 → 后续仍可见的结果”；删除后不影响后续的换图不再计为故事节点。
4. 文字进入手机画面，承担叙事而不是评审说明：每幕使用低权重地点／时刻、短标题和两到三行情境旁白；事件发生后改写正文，不叠加任务弹窗。
5. 户外文字使用深蓝墨片并避开人物、猫、主星与操作区；室内文字使用浅暖纸并落在墙面或桌边留白。大字为真实 `120%`，不使用 `SHRINK`。
6. 星空与直接回家都能完成本晚；直接回家时，同一颗流星在暖屋窗边补足。风留下的花瓣／草籽、外衣、饭菜、温水、猫的回应与留灯选择必须进入后续画面。
7. 不显示页码、任务、成功、奖励、连续天数、倒计时或完成率；草坡、流星后和暖家收束均可无限停留。
8. 组合样片的视觉与交互方向获用户通过，可作为下一阶段正式素材生产的可见依据；它不因此成为运行时资产。

## 4. 保持不变

- 成年人背影＋普通家猫、自然深蓝星空、单条宽淡断口银河、两朵弱光花、右侧稳定暖门与 B 夜漫画语言保持不变。
- 户外继续清凉、安静、舒心；室内继续是从第一帧就明亮温暖、整屋可读、角落不黑的“灯一直为你亮着”。
- 首次触碰前数字静音；首触后环境风先响应。静音仍能理解完整因果。
- 减少动态关闭位移、草浪、云推进、镜头推拉、暖光扩张和蒸汽位移，只保留不超过 `180ms` 的交叉淡化与静态结果态。
- 360×800、390×844、430×932、430×844 压力态，44×44 热区和相邻 8px 间距继续是硬停止线。

## 7. 下一停止线

本批准解锁的是 Gate B 正式生产计划，不是批量出图或开发。下一步顺序固定为：

1. 已在独立 R2 中补齐 `EYES_ADJUST` 与 `KITCHEN_CALL` 的手机内可见证明；当前停止在用户对同一 R2 页面进行可见复核。
2. 先制作一个高风险人物／猫边缘真 Alpha 探针；失败立即停止，不允许自动抠图、色键、棋盘格背景、整图底层或空层兜底。
3. 只生产三组正式动态素材探针：云／主星／猫靠近、手绘流星＋环境反光、暖屋蒸汽／生活状态。
4. 每组通过负责人、独立只读审查和用户同一文件批准后，才允许批量扩展。
5. 三组正式素材、五人故事复述和多尺寸／减动／静音证据都通过后，才另写 Cocos 生产计划。
