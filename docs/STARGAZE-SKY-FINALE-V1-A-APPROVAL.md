## 批准范围

本合同是 [`STARGAZE-SKY-FOCUS-V1-A`](./STARGAZE-SKY-FOCUS-V1-A-APPROVAL.md) 的末页追加，不新增第六幅插画，不改写 F1–F5 的星空为主构图。用户进入 F5“世界很大”后，同一末帧只播放一次下列收束：

| 阶段 | 时长 | 可见行为 |
|---|---:|---|
| 末帧静置 | `0.9s` | F5 原构图完整停留，无流星、无文字。 |
| 单颗流星 | `0.8s` | 恰好一颗流星从右上方向人物与猫上方划过；不命中小屋，不指向按钮，不形成任务引导。 |
| 尾迹淡去 | `0.45s` | 同一颗流星的短尾迹自然淡去，不留光环、十字闪光或 Bloom。 |
| 再次静置 | `1s` | 回到安静星空，不连续播放第二颗流星。 |
| 文案显现 | `180ms` | 两行文案及对应选择只做一次透明度显现，不漂浮、不脉冲、不缩放。 |

强制中文文案为：

> 一颗流星，刚刚从夜里经过。  
> 回家，还是再坐一会儿？

文案是后续 Gate B 浏览器设计板的独立 UI 层，不烘焙进 F5 插画。两个实际出口为：

- `回家`：进入既有“回家”绘本支线第 1 幅，不跳过回家故事，不直接进入室内。
- `再坐一会儿`：回到夜风草坡根场景，不记录完成、不解锁奖励，用户仍可无限停留或重新选择。

## 减少动态等价态

- F5 仍先静置 `0.9s`。
- 不运行任何流星位移、缩放、旋转、相机推进或视差。
- 只在人物与猫上方的中性位置显示一道静态流星痕，以单次 `≤180ms` 交叉淡化完成出现／消失；仍然恰好一道，不重复。
- 静态流星痕结束后保留 `1s` 安静停顿，文案仍以 `180ms` 透明度显现。

## 视觉与连续性停止线

- F5 静态底图保持无流星 clean plate；单颗流星必须是独立、可关闭的 Gate B 覆盖层，以便正常态与减动态共用同一批准构图。
- 除该末页一次、一颗外，F1–F5 的插画、入口草坡、“吹吹风”、“回家”和室内都禁止额外流星。
- 流星只是叙事句号，不能比银河更粗、更亮或更长时间占据主视觉；不得变成开箱、奖励、许愿或任务特效。
- 底图中的单条宽淡断口银河、8–10 主星、尘埃暗裂、小比例人物与猫、右侧稳定暖门、两朵弱光花和 B 深靛干笔漫画风全部不变。
