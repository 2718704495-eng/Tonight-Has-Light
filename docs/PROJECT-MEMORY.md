## 1. 我们正在做什么

《今夜有灯》是一个原创微信小游戏体验：让下班后很累的人在夜里停留 3–8 分钟，先在草坡上和一位安静的成年人及一只小猫看星空、吹凉风，再由自己决定是否进入亮着灯的小屋。它不要求完成、成长、打卡或分享，也不承诺治疗、助眠或改变情绪。

我们追求的是“静态画面本身已经好看，微动让它像在呼吸”。画面是产品主体，技术只有在把批准的画面、节奏和触感准确落地时才算完成。

## 2. 当前第一场景：夜风草坡

### 构图与星空

- 逻辑母版为 390×844。当前根页 `ROOT-WIND-HEM-V1-A` 采用天空约 `72%–78%` 的天空主导构图；成年人、普通家猫、小屋和草坡压在下方 `22%–28%` 作为安静尺度锚点。旧 `58%–62%` 天空比例只保留为 R1 历史合同。

- 人物是正常成人比例、短发、宽松上衣与长裤；肩部下沉、屈膝放松，不回头摆拍。人物不公开姓名或性别。

```text
      │                                            ├─ 回家 → 既有回家支线第 1 幅
      │                                            └─ 再坐一会儿 → 回到草坡
      ├─ 点草尖／花 → 吹吹风支线 → 点击画面逐页 → 回到草坡
      └─ 点暖门 → 回家支线 → 点击画面逐页
                         → 室内第一夜「水快开了」
                         → 互动 / 小剧场 / 安静停留 / 今晚收束
                         → 后续四夜按原模板展开
```

户外不是“第零关”或“第六夜”，也不写入五夜进度。室内五夜内容暂时保留；3/5/8 分钟选择已锁定为进屋后、核心互动前出现，默认 5 分钟，但必须由用户明确确认，不显示倒计时。

会话控制已锁定为 `FORMAL-SESSION-CONTROLS-V1-A`：暖屋先完整显示约 650ms，再以约 170ms 透明度显示右墙留时笺；5 分钟默认选中但不自动计时，用户确认 `3/5/8` 后才启动会话。确认后只保留 `48×44px` 的“停一停”纸签；设置含声音、减少动态和大字，核心完成后可主动打开已批准收尾 UI。120% 大字改用桌边暖纸，不缩字。

室内外情绪差已经由用户锁定：户外保持冷、静、通透的夜风；室内必须像深夜回家时有人一直为你开着灯并准备了晚饭，墙、天花、地板、家具、人物和猫都在明亮暖光里可读，画面角落不能黑。明亮感由广域、均匀的暖色墙顶反射与生活细节建立，不用纯白灼点、Bloom、整屏橙滤镜或奖励式闪光。用户提供的“生日进门后整屋亮起”是情绪反差参考，第一版不自动加入群像和派对。
