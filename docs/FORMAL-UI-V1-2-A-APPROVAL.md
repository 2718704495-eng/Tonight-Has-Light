## 2. 用户批准范围

1. 采用 A“灯一直为你亮着”：用户主动点门后，室内从第一帧就是稳定明亮的暖家，不播放黑房亮灯表演。
2. 室外继续是安静、清凉、通透的 V7 夜风草坡；室内以整屋明亮暖光和窗外冷夜形成清楚情绪差。
3. 墙、天花、地板、家具、人物、普通家猫与晚饭全部可读，画面角落不能黑。
4. 桌上已有朴素热饭、汤／粥、主食、壶、杯和两只碗，表达“有人为你留灯并准备了晚饭”。
5. 人物保持左侧三分之四背面、普通家猫保持右侧；人物身份、性别与关系不公开。
6. 使用明亮的蜂蜜奶油、暖纸白、浅木和柔琥珀；窗外保留深蓝夜色。整体保留水粉纸绘／染色纸层和手工颗粒感。
7. 到家方式 A 替代 B；B 不得进入当前正式母版、动效或 Cocos 构建。

## 3. 本次没有批准的内容

- 没有批准把用户参考 PNG 或 imagegen 探索 PNG 直接切片、描摹或作为 Cocos 生产资产。
- 没有批准画面中的可识别人像相框、特定家庭关系、生日人群、派对、彩带、蛋糕或欢呼。
- 没有批准多余第三灯具、纯白灼点、Bloom、整屏橙滤镜、黑角或奖励式闪光。
- 没有批准新的室内核心玩法、音乐、触碰音效、正式动效数值、Cocos 候选、微信预览、上传、审核或发布。

## 4. 生产边界与下一停止线

- 下一交付物是 `390×844` 原创、可编辑、分层的正式静态母版；必须独立重绘人物、猫、空间、灯、饭菜、壶、杯、窗和家具。
