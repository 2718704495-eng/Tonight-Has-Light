## 3. 主持词

逐字说：

> “接下来会先看到一张很小的图，再看到一段很短的无声画面。不是记忆考试，也没有正确答案。请说你第一时间真实看到和感到的内容；我在你回答前不会介绍作品。”

在全部开放题结束前，主持人禁止说“星空、成年人、猫、风、草、凉快、舒服、自然、任务、门、抖动、焦虑”。

## 4. 每人流程

1. 将 H-T 以约 `98×211 px` 显示 3 秒，立即隐藏。
2. 依次问并逐字记录：
   - “第一眼你看到了什么？”
   - “画面里正在发生什么？”
   - “你觉得画面里有哪些人或东西？它们在看哪里？”
   - “你会想立刻点某个地方或完成什么吗？为什么？”
3. 显示中性黑屏 5 秒。
4. H-M 原速、无声播放一次，结束后隐藏。
5. 依次问并逐字记录：
   - “刚才发生了什么？请按你看到的先后顺序说。”
   - “哪些地方动了？最先、接着、最后分别是什么？”
   - “这段画面给你的第一感受是什么？”
   - “如果想到空气、温度或身体感觉，你会怎么形容？”
   - “有哪个动作让你觉得不自然吗？为什么？”
6. 主持人只能记录原话和可观察事实，不能替参与者补答案。

## 5. 二元通过线

五项全部满足才是 `PASS`：

- 至少 `4/5` 自发理解为自然夜空。
- 至少 `4/5` 自发说出一位成年人和一只普通家猫共同仰望。
- `0/5` 把画面理解为任务地图、关卡路线或必须马上进门。
- 至少 `4/5` 在未被点名对象前，按顺序说出“草/植物→人物/衣发→猫/耳尾”。
- 至少 `4/5` 自发说出凉快、舒服、自然或完整协议允许的同义表达；认为抖动、风太大或焦虑的人数须 `<2/5`。

样本不足、被主持词提示、重复播放或原话缺失都记 `BLOCKED`；足额有效样本低于任一阈值才记 `FAIL`。
