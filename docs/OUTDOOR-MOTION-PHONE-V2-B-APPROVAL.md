## 获批范围

- 为当前可丢弃户外体验制作一张 `motion-ready clean plate`：只还原远草、近草、人物发梢／衣角、猫耳／尾尖六个既有 ROI 背后的静态副本。
- 六个局部改为常驻、不透明、同源的真实内容层；中性合成必须与获批 V7 对位，ROI 外像素不得改变。
- 六段时序与峰值严格采用提案 B：

| 通道 | 开始／峰值／结束 | 峰值角度 |
|---|---:|---:|
| 远草 | `0 / 800 / 2500ms` | `-2.6°` |
| 近草 | `300 / 1250 / 2800ms` | `-4.2°` |
| 人物发梢 | `1150 / 1850 / 3000ms` | `-4.6°` |
| 人物衣角 | `1350 / 2150 / 3250ms` | `-5.2°` |
| 猫耳 | `2350 / 2900 / 3500ms` | `-5.4°` |
| 猫尾尖 | `2550 / 3250 / 4050ms` | `-7.6°` |

- 六通道不附加平移、缩放、回弹或累积漂移。人物／猫呼吸上限为 `0.8% / 0.9%`。
- 场景稳定约 `900ms` 后开始第一阵风；首触空闲时同帧启动视觉风，尾段首触至完整新链等待不超过 `250ms`；不得叠加。
- 第一条风结束后安静 `4.5–6.5s`，之后每次安静 `6–9s`。
- 允许制作新的本地候选、自动测试、Web 构建、原速录屏、四尺寸／减动／性能证据和独立 QA 输入。

## 明确保持不变

- V7 的成年人背影＋普通家猫、构图、材质、配色、单条银河、十颗主星、小屋、稳定门光、两朵花、暖屋和所有 UI。
- 银河、房屋、地平线、相机和整屏 transform 恒为 `0`；不新增粒子、Bloom、Shader、动态模糊、3D 灯光、按钮、教程或任务提示。
- 星、花、云和门沿用获批上限，不借本次修复增强。
- 首触前数字静音；首触后只沿用已批准环境风。音乐仍未批准。
- 减少动态时六个风通道、人物／猫呼吸、云位移和视差 transform 全为 `0`；只允许≤`180ms`、亮度增量≤`0.04` 的静态等价反馈。
- V7 和本次派生层仍是可丢弃体验资产，不因此成为正式生产资产。
