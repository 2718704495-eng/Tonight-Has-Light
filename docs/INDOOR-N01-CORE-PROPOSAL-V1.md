# 第一夜核心互动提案 V1：灯本来就亮着

> 日期：2026-08-24  
> Gate：B2／正式室内体验  
> 上游决定：`FORMAL-UI-V1.2-A / 灯一直为你亮着` 已批准  
> 当前状态：`BLOCKED / AWAITING USER APPROVAL`  
> 负责人推荐：`INDOOR-N01-CORE-V1 / 壶盖轻响`

## 1. 为什么必须替换旧玩法

旧核心“把一小团暖光拖到壶边”当前状态为 `DRIFT / BLOCKED`：它把温暖设计成用户完成动作后的奖励。现在房间从第一帧就明亮、晚饭也已备好，继续拖光会产生明显疑问：家已经这么亮，为什么还需要这团光？

新核心不再让用户“制造温暖”，而是让用户注意到：水和饭一直替你温着。所有方案均无失败、无评分、无进度条、无强制拖拽；静音与减少动态也能完成。

## 2. 三个方案

### 方案一：壶盖轻响（推荐）

- 用户轻触水壶、壶盖或蒸汽上方约 `120×112px` 的宽松区域。
- 一缕蒸汽变成三缕，壶盖轻轻回应；约 `600ms` 内记为核心完成。
- 不显示箭头、进度条或反复发光；点偏没有惩罚，提前触碰也有效。
- 10 秒无操作时只出现一句：“壶里的水，正轻轻响着。”用户仍可继续不操作。
- 静音依靠蒸汽状态变化理解；减少动态使用两张壶／蒸汽静态状态，在不超过 `200ms` 内交叉淡化。

优点：完整保留第一夜“水快开了”和收尾“水热了。你也先缓一会儿。”，不增加大型道具，也最符合“灯、饭和水本来就在等你”。

### 方案二：把杯子靠近一点

- 用户点杯子或壶边空位，人物把杯子自然挪近；短拖可作为增强，但轻触必须是完整等价路径。
- 杯子宽松吸附，不存在放错、失败或重来。
- 水汽随杯子靠近变得更清楚，随后进入斟水与杯子小剧场。

风险：仍带一点“帮忙摆桌”的任务感，也可能让用户误以为杯子初始位置是错误状态。

### 方案三：揭开保温饭罩

- 用户轻触饭罩，人物揭开已经准备好的汤或粥，热气出现。
- 静音靠饭菜与蒸汽状态理解；减少动态直接交叉切换“盖着／揭开”两态。

风险：需要增加饭罩和揭盖动作，并削弱第一夜“水快开了”的标题与收尾因果；更适合后续夜晚，不推荐 N01。

## 3. 推荐方案中的杯子小剧场

1. 壶的蒸汽回应，核心先记为完成。
2. 人物顺手拿起桌边倒扣的备用杯，停顿约 `0.8s`。
3. 猫只闻一下，再用前爪轻碰一次；猫不拟人、不替用户完成。
4. 用户可轻触杯子提前继续；`4s` 不操作，人物也会自己发现并翻正。
5. 人物倒水，出现：“水热了。你也先缓一会儿。”

减少动态时不播放杯子旋转，改为倒扣／正放两张静态 Sprite 的短交叉淡化。正式母版需增加一个“备用杯倒扣初态”；它属于本玩法的可见变更，只有用户批准本方案后才能加入正式资产。

## 4. 3／5／8 分钟节奏

| 时长 | 内容 |
|---|---|
| 3 分钟 | 明亮暖家 → 选择时长 → 壶盖轻响 → 杯子小剧场 → 安静停留 → 约 3 分钟出现收束 |
| 5 分钟 | 同一主流程；杯子后开放窗雾与围巾两个可选互动，中间保留安静空白 |
| 8 分钟 | 不增加第三个任务；延长热气、人物呼吸、猫安静卧下和窗外夜色等非交互环境段落 |

所选时长只决定收尾提示的最早出现时间，不显示倒计时；提示会等待正在播放的小片段结束。核心完成后可以提前结束，未操作也能继续安静停留。整屋暖光始终稳定，不为了收尾重新压暗。
