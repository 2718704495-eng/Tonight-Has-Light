# 《今夜有灯》户外入口夜空方向（V7 当前基线）

> 当前决定：用户已批准 V7“自然星空＋单条淡银河＋成年人背影与家猫”进入 Gate C。V4-B 是历史构图来源；V7 方向图只作样片基准，正式入包资产仍需重新分层绘制。

V3 方向停止深化。问题不在星星数量，而在“月牙＋斜银河＋流星＋均匀星点”缺少独特构图，缩到手机后容易成为蓝色噪点。

## 方向 A：星幕穹顶（未选）

- 删除月亮、银河和流星。
- 一条巨大的银蓝云幕从左侧地平线拱过画面，再落向右侧小屋。
- 上方只保留一大一小两颗相邻主星，呼应地面的两个角色。
- 优点：安静、原创、缩略图记忆点强，Cocos 分层成本低。
- 风险：星星偏少，不完全满足“星空本身非常漂亮”的期待。

## 方向 B：星河穹顶（历史来源）

- 星河从左上形成弧形天顶，再向右侧小屋收束，不斜穿画面。
- 星星主要集中在星河内部，中央保留大面积干净深蓝，形成疏密节奏。
- 两层薄云从星河前方经过，建立真实纵深。
- 两朵微光小花分别靠近角色，与天空的冷色星光呼应。
- 优点：直接回应“夜空更美、星星更漂亮”，并用星河自然引导用户看向小屋。

V7 已将其修正为：

1. 普通深蓝星空成为主体，只留一条宽而淡、边缘松散的自然银河。
2. 银河内部保留暗色尘埃纹理、亮度不均和明显断口；禁止多条平行发光飘带。
3. 只有 8–10 颗主星参与极慢亮度变化，其余星尘与银河全部烘焙在静态底图。
4. 地面角色改为正常成人比例的卡通背影与普通家猫，并沿用右侧小屋、路径与恰好两朵花的构图。

## 禁用元素

- 常见海报式月牙。
- 平直、等宽或多条平行的银河发光贴图。
- 满屏等密度星点。
- 十字闪光、频繁流星、霓虹紫极光。
- 角色互相对视而没有共同仰望天空。
