# FORMAL-SESSION-CONTROLS-V1 · 会话控制 UI 提案

> 状态：`V1-A APPROVED / LOCAL SOURCE PASS / RUNTIME BLOCKED / NO BUILD / NO UPLOAD`

## 1. 现状问题

- 当前一次性暖屋样片会静默采用 `5 分钟`，与正式合同“默认 5，但用户必须明确确认”不一致。
- 核心完成后虽然领域层支持提前结束，画面上没有可发现入口。
- 声音、减少动态和大字已有设置数据，但缺少获批的室内入口；直接套系统弹窗或 HUD 会破坏明亮暖家。

## 2. 研究结论

- 选择应短、一次性、避免滚动；Apple HIG 提醒选项越多，决策负担越高，Action Sheet 通常以三项选择为宜：<https://developer.apple.com/design/human-interface-guidelines/action-sheets>。
- Calm Technology 强调信息应从边缘进入注意、需要时再进入中心，因此设置采用折叠入口而不是常驻面板：<https://calmtech.com/papers/designing-calm-technology>。
- WCAG 2.2 的最小目标强调目标尺寸与间距可减少误触；本项目继续使用更严格的 `44×44px` 与 `8px` 间距：<https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html>。
- 当前暖屋与收尾已经批准暖纸语言；复用材质和位置比引入玻璃、抽屉或新图标更能维持设计一致性。

## 3. 三案

### A · 右墙留时笺（推荐）

- 390×844：纸笺约 `x=184–373 / y=204–500`；不越过星窗，底边不碰晚饭。
- 沿用 `FORMAL-ENDING-UI-V1-A / 灯下留笺` 的纸色、墨字、茶褐边和右墙位置。
- 5 分钟默认以不发光的双墨圈表示；用户必须再点动态确认键才开始。
- 确认后只留 `48×44px` 的 `停一停` 纸签；核心完成后设置内出现 `看看今晚的留笺`。
- 优点：一致性最好、遮挡少、资产和 Cocos 复用成本最低。
- 缺点：右墙窄；120% 大字必须切换桌边暖纸。

### B · 墙上三枚纸签

- 三个时长作为独立纸签纵排，选中项只有墨圈和纸色差。
- 优点：几乎不出现大面板，数字适配稳。
- 缺点：容易读成任务清单或收集物；新增木轨与多纸签，制作成本最高。

### C · 右墙暖纸抽屉

- 设置与时长都放入右侧可展开抽屉。
- 优点：信息层级最清楚、扩展声音二级页容易。
- 缺点：面积最大、最像传统 HUD，位移动效也更容易抢暖屋焦点。

## 4. A 的行为脚本

1. 暖屋真正加载后，先显示约 `650ms` 完整明亮房间。
2. 纸笺在 `170ms` 内仅透明度显现；减动模式直接显示。
3. 默认选中 5 分钟，但计时为零；选择 3/5/8 只改墨圈和确认文案。
4. 用户触碰 `就坐 X 分钟` 后，纸笺淡出并启动 NightSession；无倒计时。
5. `停一停` 打开声音、减少动态、大字；声音进入二级页分别控制环境声、音乐、触碰声。
6. 核心完成后，设置增加 `看看今晚的留笺`，打开已批准收尾 UI；不会直接完成今晚。
7. 纸外触碰收起设置；设置展开期间不把触摸传给壶、杯或其他房间热区。

## 5. 提示词／人工绘制说明 V1

> 在已批准 `FORMAL-UI-V1.2-A / 灯一直为你亮着` 的 390×844 明亮暖屋上设计会话控制。人物、普通家猫、晚饭、壶、灯、星窗、构图、材质、配色和光线全部保持原样。暖屋完整显示 650ms 后，在右墙 `x=184–373 / y=204–500` 放一张窄暖纸留时笺，沿用已批准“灯下留笺”的水粉纸纹、细毛边、深褐墨字和茶褐边，不加暗幕、玻璃、发光、Bloom 或系统弹窗。内容为“今晚想坐多久？”、“只是决定多久后提醒你。没有倒数，随时都可以停下。”，三个 44×48 以上时长选项 3/5/8，间距至少 8；5 分钟默认用不发光双墨圈选中，确认键文案“就坐 5 分钟”，另有低权重“先回到夜风里”。确认后纸笺只透明度淡出，右上墙留下 48×44 的“停一停”小纸签。设置沿同一纸笺材质展开，显示声音、减少动态、大字模式；核心完成后增加“看看今晚的留笺”。120% 大字不缩字，改用已批准“桌边暖纸”。减动状态 transform 全为零。

## 6. 保持不变与风险

- 不改：户外 V7、可感知微风、暖屋亮度、人物/猫、壶杯节奏、正式收尾纸笺、分享文案。
- 不接入：未批准音乐、临时暖屋图的正式生产使用、任何新微信包。
- 性能：只需要一张小纸面、文字、少量 Button/Sprite；不需要粒子、实时模糊或新灯光。
- 原创：纸面结构需人工可编辑 SVG/PNG；参考图继续只作设计板背景。
