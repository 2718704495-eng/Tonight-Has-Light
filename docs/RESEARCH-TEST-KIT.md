# 原创盲测与体验测试工具包

> 版本：v1.0  
> 使用原则：测试只验证当前原型，不作医疗、心理诊断或统计学结论

## 1. 隐私与主持原则

- 参与者使用 P01–P08（原创盲测）或 E01–E10（体验测试）编号，不在表单记姓名、微信号、头像、公司或精确住址。
- 录音/录屏前单独征得同意；不同意也可参加纸笔记录。
- 参与者可随时停止，无需说明原因。
- 主持人不辩解设计、不暗示“正确答案”、不将多人组在一起互相影响。
- 原话可匿名记录；报告中将观察事实、参与者原话和团队推断分开。

## 2. 8 人原创盲测

### 2.1 参与者条件

- 8 名未参与策划、绘制、动画或内部评审的人。
- 可以是用户的朋友，但不能在测试前告知参考 IP 或设计避让项。
- 每人单独测试，提交后不回看或改答案。

### 2.2 刺激材料

1. `48×48px` 纯黑剪影并列图，随机左右顺序，展示 3 秒。
2. 两角色中性正面图，无房间、名字、台词或品牌字样，展示 8 秒。
3. 10 秒无声动作：A04 各自移动＋R02 扶正反杯，无 UI 和上下文。

每位参与者使用同一版本、同一显示设备与时长。角色左右顺序在 8 人中各占一半。

### 2.3 主持词（逐字）

> “接下来会看到两个正在设计的角色。这不是记忆考试，也没有正确答案。请只说你第一个想到的东西；我在你回答前不会介绍角色。”

不说“熊”、“灯灵”、“原创”、“像不像某 IP”或项目的参考背景。

**标准化规则**：只合并同一 IP/品牌的明确别名；不把“像小动物”、“像灯”这类一般联想强行归到某 IP。原回答必须保留。

**立即停止线（任一触发即 FAIL）**：

1. 2 人或以上在未被告知参考的前提下，独立提及同一现成 IP。
2. 3 人或以上选择“更像换皮”或“明显换皮”。

**48px 剪影线**：至少 7/8 立即区分两种本体，且至少 6/8 在 30 秒后正确匹配。

盲测失败后暂停进入开发，先修改轮廓、本体、运动方式或关系动作，然后用 8 名新参与者重做全套盲测。该门槛是项目内部预警，不是法律无风险结论。

## 3. 6–10 人体验测试

### 3.1 测试前配置

- 使用 Gate C 同一构建号，首次进入、本地存档清空、默认 5 分钟。
- 尽量使用参与者自己的手机和日常屏幕亮度，记录设备型号、系统、微信和基础库版本。
- 至少 2 人全程静音，2 人使用减少动态，2 人使用大字；可交叉，但每种模式至少有 2 份完整样本。
- 主持人在首个可交互画面出现后的 10 秒内保持沉默，不指屏幕、不说“那个会亮”。

### 3.2 开场主持词（逐字）

> “这是一段大约三到八分钟的小游戏原型。它没有失败和评分，也不是心理测试。请像平时一样自己使用，想停就可以停。我先不教你怎么玩；如果碰到技术问题，可以告诉我。”

不使用“疗愈”、“减压”、“正念”、“助眠”引导期待。

### 3.4 结束访谈（按顺序询问）

1. **“如果用一句话说刚才发生了什么，你会怎么说？”**
2. **“有哪一刻你不知道要做什么？”**
3. **“有哪一刻让你觉得被催、要完成任务，或担心做错？”**
4. **“与刚打开前相比，你现在更紧一点、差不多、松一点，还是说不清？”**
5. **“如果朋友发来‘有人给你留了一盏灯’，你会觉得温暖、有压力、不明白，还是其他？为什么？”**
6. **“你愿意保留哪一个画面或声音？最想去掉什么？”**
7. **“你会在什么时候再打开？如果不会，也可以直接说。”**

记录 Q4 单选与全部原话，不用主持人总结替代。

### 3.6 计算与通过线

- **首动作发现率** = `10 秒内首次有效动作人数 / 完成测试人数`，通过线≥80%。技术崩溃中断的样本不计入分母，但必须单列报告。
- **收尾到达率** = `到达收尾画面人数 / 完成测试人数`，通过线≥70%。玩家主动按“结束今晚”且正常到达收尾视为到达。
- **状态不恶化比例** = `(松一点 + 差不多) / 愿意回答 Q4 的人数`，必须超过 50%；同时单列“松一点”数量，不将“差不多”写成减压成功。
- **任务化预警**：2 人或以上自发表示“像打卡”、“必须养”、“怕不回来会出事”时，视为 Major，重做文案/推进机制并复测。
- 样本少于 6 人时不出 Gate C 结论；6–10 人的百分比与原始人数必须一起报告。

## 4. 一周后可选回访

不提醒参与者打开。一周后只询问：**“过去一周里，你有没有自己再打开过这个原型？”** 回答记为是/否/不愿回答，不查看微信使用记录。此指标用于判断是否值得扩充内容，不是 Gate B/C/D 硬门槛。
