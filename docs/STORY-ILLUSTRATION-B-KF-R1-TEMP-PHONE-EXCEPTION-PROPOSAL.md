## 一句话说明

把你已经认可的 B 风格三张故事图，临时放进一个新的微信开发版 `0.4.7`，让你直接在手机上体验：

**看夜空 → 风吹过 → 风停下来 → 随时点门进入温暖房间。**

这三张图只用于这一次手机体验，不会被当作最终正式素材。正式版本以后仍会换成真正完成分层重绘的插画。

## 为什么建议这样做

目前 B 风格的故事、三幅画面和转场节奏都已经得到你的认可。

我们也尝试过把它重新制作成正式分层 SVG，但两次结果都不够好：人物坐姿不自然、猫像图标、银河和草坡也没有原 B 图的漫画质感。所以我已经停止这条低质量路线，没有把失败稿交给 Cocos。

如果一直等正式插画全部重绘完成，你暂时无法在手机上判断完整体验。这个临时方案可以先验证真正重要的部分：

- 三幅画面连起来有没有故事感；
- 每次换画是否流畅；
- 风声和画面节奏是否舒服；
- 换画过程中点击小屋，能否立刻进入暖屋；
- 户外清凉、室内温暖的情绪反差是否成立。

## 手机里会怎样播放

1. 第一幅「坐稳」停留约 `3.2 秒`。
2. 用约 `0.3 秒` 的柔和转场进入第二幅「风经过」。
3. 第二幅停留约 `1.5 秒`。
4. 用约 `0.36 秒` 的柔和转场进入第三幅「余风」。
5. 第三幅会安静停留，不自动循环，也不会强迫用户进屋。

整个过程中：

- 小屋的门从第一秒就可以点击；
- 无论正在看哪一幅或正在转场，点门都应立即停止户外故事并进入暖屋；
- 第一次触碰屏幕后继续使用目前已经确认没问题的风声；
- 不增加新音乐；
- 开启“减少动态”后固定显示第一幅，不自动换画，但仍可点门、开关声音和进入房间；
- 室内继续使用已经批准的明亮暖屋，不改变暖屋、留时笺、收尾界面和存档逻辑。
