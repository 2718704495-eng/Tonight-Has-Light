# 角色圣经：成年人背影＋普通家猫

> 版本：V7 角色结构 + STORY-ILLUSTRATION-REDESIGN-V1-B 户外视觉语言选择  
> 状态：当前角色合同  
> 公开命名：第一版不公开人物姓名、性别或与用户的具体关系；猫也不命名

## 1. 角色任务

人物承担用户投射，小猫提供轻微生命感。两者不是主角登场式摆拍，也不负责讲道理；第一场景中只安静坐在草坡上，共同看向同一片星空，让用户自然加入这段停留。

## 2. 不可改变的轮廓

### 2.1 人物

- 正常成年人比例，背面或四分之三背面；短发、宽松上衣与长裤。
- 坐姿为自然屈膝，肩部下沉，脊背略松，不回头迎接镜头。
- 性别表达克制，不使用裙摆、蝴蝶结、浓妆、胡须或明显职业制服来固定身份。
- 不做大头短肢、幼童比例、网红剪影或夸张动漫发型。

### 2.2 小猫

- 普通家猫比例，四足动物骨架；安静坐姿，尾巴绕在脚边。
- 不穿衣、不直立、不拿道具、不做人的手势或表情。
- 耳朵、背线和尾巴必须在 48px 黑剪影中仍能读成猫，而不是第二个小人或玩偶。

### 2.3 同框关系

- 人物在左、小猫在右，靠近但不拥抱；两者之间保留自然空气缝。
- 头轴与身体朝向指向同一天区，不互看、不看门、不看用户。
- 不使用爱心、牵手、亲吻、眼泪或煽情姿态定义关系。

## 3. 材质与受光

- V7 的明亮水粉纸绘/染色纸层只保留为历史动态样片基准。2026-08-28 用户选择 `STORY-ILLUSTRATION-REDESIGN-V1-B` 后，户外新候选改用深靛有限色无字夜漫画：大块明暗、干笔墨线、克制网点和纸张颗粒；角色、山、草与小屋必须共享同一线重、颗粒尺度与套色逻辑，禁止把旧水粉角色直接贴入新漫画背景。
- 上述选择只锁定视觉语言；`STORY-ILLUSTRATION-REDESIGN-V1-B-KF-R1` 三帧和正式分层资产仍待批准。室内 `FORMAL-UI-V1.2-A` 明亮暖家不随本条改色或改材质，室内外转场的材质桥接在后续单独验收。

- 冷星光只在人物发梢、肩线、猫耳与背线形成薄边。
- 门是唯一明显暖源；两朵花只保留局部弱光。人物和猫不带内部发光器官。
- 禁止将生成图的笔触直接当正式角色资产；Gate D 前必须原创分层重绘并登记来源。

## 4. 动作语法

### 4.1 人物的重量

- 呼吸周期建议 `4.2–5.6s`，主要发生在肩背 `1–2px` 的慢起伏；不做整个人上下漂浮。
- 风来时先动发梢，再动上衣下摆；幅度小、回落慢，体现布料和身体重量。
- 看星只允许肩颈微抬约 `1–2°`，不突然转头。

### 4.2 猫的生命感

- 呼吸周期建议 `3.2–4.6s`，与人物错相；胸背仅有极轻变化。
- 每 `12–25s` 可随机出现一次耳尖转动或尾尖轻摆；不可固定同周期循环。
- 风来时耳缘先轻动，尾尖可多保留一小段余韵；身体不弹跳。

### 4.3 共同动作

- 普通风传递：远草→近草→人物发梢/衣角→猫耳/尾尖。
- 点天空：邻近星星回应，人物肩颈微抬，猫耳转向该天区。
- 点门：人物先轻回头，小猫耳朵朝门；进入正式开发前另做转场关键帧，不在 Gate C 的零操作主样片里强演。

## 5. Gate C 分层最小集

Gate C 是可丢弃动态样片，允许使用从 V7 方向重建的样片资产，但必须保持持久节点和独立层：

1. 人物：身体、头/发梢、上衣下摆、冷边光、接触影。
2. 小猫：身体、耳朵、尾巴、冷边光、接触影。
3. 两者 Pivot 与转轴必须标注，不能把整张人物＋猫合成图上下缩放冒充呼吸。
4. 减少动态时使用中性静态姿势，关闭位移和旋转，只允许 `≤200ms` 的透明度/亮度反馈。
