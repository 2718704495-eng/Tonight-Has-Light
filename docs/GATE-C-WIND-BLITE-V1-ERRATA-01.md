# GC-WIND-BLITE-V1 合同勘误 01

> 日期：2026-08-24

## 1. 发现的矛盾

原批准文档同时写了两组不能并存的要求：

1. 角色、构图、银河、主星、门、花、云、呼吸和音频全部保持 Wind A/V7 既有合同不变；B-lite 只允许修改四个角色局部风通道。
2. 机器停止线写成“`t≥5s` 与 V7 全像素零差”。

既有时间轴在 5 秒后仍有获批的云层缓慢变化和主星错峰微亮，因此第二条若按整幅画面字面执行，就必须擅自关闭未获准改变的星云动效，反而违反第一条和用户批准范围。

## 2. 有效纠正

原文下列两处：

- “t=0、t≥5s、tail 与 reduced-motion 必须继续与 V7 全像素零差。”
- “t=0、t≥5s、tail、reduced 与 V7 全像素零差。”

统一解释并纠正为：

- 六个风通道及其对应局部 transform/overlay 必须在 `5000ms` 全部归零；不得残留风位移、旋转或风层亮度。
- 整幅画面全像素零差只在 `t=0`、`t=9800ms/tail` 和 `reduced-motion` 中性态执行。
- 5 秒附近仍按既有未改变合同保留云、主星、花和呼吸时间轴；这些通道不属于 B-lite 的修改范围。

## 3. 不受影响的批准内容

- B-lite 推荐表的四个局部 start/peak/end、旋转角和逐通道 overlay 上限不变。
- 远草、近草及 `0.22` overlay 不变。
- V7 角色、构图、材质、配色、银河、主星、小屋、门、道路、花、云、呼吸、音频和减动中性态不变。
- 保守备选仍未获批准。
- 不需要修改当前候选代码、资产、构建或冻结证据；独立 QA 应同时引用原批准文档 SHA 与本勘误 SHA。
