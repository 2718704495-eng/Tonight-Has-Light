# 《今夜有灯》正式可见体验提案 V1.2：明亮暖家

> 日期：2026-08-24  
> 阶段：Gate B2（正式室内 UI 与体验承接）  
> 用户已锁定的体验原则：`ALIGNED / 户外安静舒心，屋内明亮温暖，像有人为你留灯并准备晚饭`  
> 到家方式：`ALIGNED / FORMAL-UI-V1.2-A USER APPROVED FOR EDITABLE MASTER`  
> 批准记录：[`FORMAL-UI-V1-2-A-APPROVAL.md`](./FORMAL-UI-V1-2-A-APPROVAL.md)  
> 可见对照板：[`design-board/formal-ui-v1-2/index.html`](../design-board/formal-ui-v1-2/index.html)

## 1. 用户纠正与根因

V1.1 把“夜间舒适”误解为“暗房中的局部小灯”，保留了过多黑角。它表达的是清冷、独处和克制，不是用户要的“深夜回家，发现家里灯亮着、饭已经准备好”的被等待感。

V1.2 撤销以下内容：

- 撤销“房间角落仍保留黑暗”。
- 撤销“暗部占 55%–65%、只有小块暖光可读”。
- 撤销以单个小灯池承担全部温暖的构图。

新目标是：户外继续冷静、清凉；门内是完整、明亮、温暖、可看清生活细节的家。角落不能黑；黑暗只存在于门外和极少量物体固有阴影，不能吞掉墙、地板、家具、人物或猫。

## 2. 明亮不等于刺眼

- 一项室内模型实验中，昏暗照明的舒适评分最低，正常与明亮照明明显更高；暖色环境在正常和明亮照明下也获得更高评价。这支持用户要求的“明亮暖家”，但实验场景不是小游戏，结论只作设计边界。[室内照明与视觉舒适研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9851505/)
- 在工作面照度不变时，更均匀的间接顶光通常获得更积极的房间评价；个体偏好仍有差异。因此画面用墙面、天花和地面的广域暖反射来建立明亮感，不依赖一个高亮灯泡。[直接／间接光与空间评价研究](https://research.tue.nl/en/publications/putting-the-ceiling-center-stage-the-impact-of-directindirect-lig/)
- 感知亮度不仅由光源强度决定，也与墙面和天花在视野中的亮度分布有关。因此可以让“世界里很亮”，同时控制手机像素不过曝、无纯白灼点、无 Bloom。[空间亮度研究](https://research.tue.nl/en/publications/from-luminance-to-brightness-a-data-driven-approach-to-support-br-2/)

这形成一条工程原则：`场景语义高亮度，屏幕输出中亮度`。所有“暖心”仍通过用户开放题验证，不作医疗、助眠或心理治疗承诺。

## 3. 到家方式决定

用户已批准 A“灯一直为你亮着”进入可编辑正式母版阶段。B 只作为历史备选保留，不得进入当前母版、动效或 Cocos 构建。

### A：灯一直为你亮着（用户已批准）

- 户外第一秒即可看到门内稳定暖光，但门不闪、不催促。
- 用户主动点门后，约 0.7–0.9 秒完成冷夜到明亮暖家的纸层交叉；室内从第一帧就是亮的，没有黑房中间态。
- 桌上已有简单晚饭、热汤／粥、主食、两只碗、壶和杯；椅背有围巾或毯子，表达“有人为你留着”。
- 优点：最安静、最像回家、不惊吓；也最符合第一夜“水快开了”。
- 风险：原“把一小团光拖到壶边”的核心因果会变弱，必须另行改写，不能假装不受影响。

### B：进门后整屋亮起（未批准／历史备选）

- 进门后的第一帧只保留极短、可读的中性暗态；在 0.45–0.55 秒内，顶灯和墙面暖反射一起亮起，饭菜、人物和猫同时被看见。
- 不加入真正的生日派对、人群、彩带或欢呼；这里只借用“疲惫回家后被惊喜接住”的明暗反差。若未来要做群像生日内容，应作为独立夜晚重新立项。
- 优点：灯光照亮黑暗的因果最强，第一眼记忆点更明显。
- 风险：更像一次揭晓，可能比 A 刺激；必须禁止闪烁、纯白跳变和奖励音。
- 减少动态时不播放亮灯过程，直接稳定切到同一明亮最终态。

负责人推荐 A。它把温暖放在“家一直等着你”，而不是“用户必须做对一个动作才得到温暖”。

## 4. 明亮暖家的视觉合同

### 4.1 空间与光

- 室内可见墙面、天花、地板和家具全部有暖色信息，画面四角也能辨认材质与边界；禁止黑角和大片冷蓝墙面。
- 使用两级真实光源：原创简洁顶灯提供均匀环境暖光，桌边／墙边小灯给饭菜与人物猫补一层更暖的局部光。正式稿删除多余第三灯，避免像灯具陈列。
- 灯泡与纸罩不得出现纯白灼点；用大面积蜂蜜奶油墙面、浅木地板和纸白餐具制造“亮”，而不是提高单点峰值。
- 窗外保留小块 V7 深蓝夜，作为冷暖对比和来处；它不能成为室内主光源。

### 4.2 色彩与材质

- 主色：蜂蜜奶油、浅木棕、柔琥珀、纸白、低饱和陶土；轮廓使用暖深褐，不用黑色压死。
- 窗外继续使用深海军蓝 `#06265F` 与稀疏星空；不得把室内重新染成蓝紫。
- 正式版仍为水粉纸绘／染色纸层、固定尺度颗粒和柔和毛边；禁止偏写实成品、塑料感、霓虹、实时 Bloom 与满屏光雾。
- 人物仍在左、普通家猫仍在右；成年人正常比例、三分之四背面，猫不穿衣、不直立、不拟人。

### 4.3 晚饭语义

- 饭菜只需一份热汤／粥、主食、两只碗、壶与杯，足以表达有人准备；不是豪华宴席，也不出现品牌包装。
- 不出现生日蛋糕、彩带、群像或具体关系称呼；人物身份、性别和关系继续留白。
- 热气使用 2–3 缕低频水粉纸帧；静音和减少动态时也能由碗、壶、摆放和暖光读懂“饭是热的”。

## 5. 原核心互动受到的影响

当前 N01 的“把一小团暖光拖到壶边”与整屋已经明亮的画面发生因果冲突，状态标记为 `DRIFT / BLOCKED`，本轮不修改代码。

到家方式已经确定为 A；下一步单独提交与“整屋已亮、饭已备好”一致的玩法提案：

- 当前有效方向：门本身完成“回到亮着灯的家”，室内核心可改为揭开保温罩、靠近热汤或触碰壶盖，让热气回应；不再把温暖设成奖励。
- 已排除方向：首次触碰让整屋亮起；该行为属于未获批准的 B，不得作为当前核心交互。

无论哪案，猫只闻／轻碰杯子，人物自己翻正；3/5/8 分钟、无倒计时、收尾、分享、暂停、恢复、静音、大字和减少动态边界保持不变。

## 6. UI 与分享

- 时长面板使用暖纸、奶油白与深褐文字，不再使用户外冷蓝大卡；场景仍是主体。
- 收尾时整屋暖光保持稳定，不把房间再次压暗；只让叙事字出现：“水热了。你也先缓一会儿。”
- 分享卡使用明亮暖家、饭菜、人物＋猫与小块冷窗，固定文案仍为“有人给你留了一盏灯”。
- 热区至少 44×44，相邻边缘至少 8 px；大字真实 120%，正文对比不低于 4.5:1，关键图形不低于 3:1。

## 8. 验收与批准语句

- 3 秒盲测中，至少 8/10 主动说出室内“明亮／温暖／像家／有人准备了饭”中的至少一项；至少 8/10 能明确区分户外安静冷夜与室内明亮暖家；0 人认为室内仍是暗房。
- 25% 缩略图仍能分出整屋暖光、晚饭、人物＋猫和冷窗；人物左猫右不漂移。
- OLED 约 20% 亮度下四角仍能看清墙、地板和家具；LCD 约 60% 下灯罩、饭菜与纸白不过曝。
- 用户已于 2026-08-24 使用批准语句 `批准 FORMAL-UI-V1.2-A 灯一直为你亮着`，并提供本轮用户批准参考图；批准证据见 [`FORMAL-UI-V1-2-A-APPROVAL.md`](./FORMAL-UI-V1-2-A-APPROVAL.md)。
- 两次纯矢量母版尝试因视觉质量不足已由负责人否决；当前仍处于正式母版制作路径决定阶段，第二次视觉确认前不得进入 Cocos。
