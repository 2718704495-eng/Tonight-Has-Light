# OUTDOOR-ILLUSTRATION-WIND-V1-A 故事板与转场合同

> 日期：2026-08-27  
> 状态：`STYLE APPROVED / STORYBOARD NEXT / NO BUILD / NO UPLOAD`  
> 依据：用户批准 `OUTDOOR-ILLUSTRATION-WIND-V1-A：五幅风页`，并追加“每个跳转要有流畅的转场”。

## 1. 画面结构

- 画布：`390x844` 竖屏，适配时按现有 `SHOW_ALL` 与安全边策略处理。
- 稳定上景：星空、银河、远山、小屋、门和地平线保持 V7 位置、色调和曝光；五帧之间不得漂移。
- 换帧下景：F0-F4 每帧都是完整的草坡、人物和猫，不使用半透明残影或碎片旋转代替主体变化。
- 接缝：上景与下景用 `24-36px` 草缘重叠遮住；人物坐骨点、猫后腿落点、两花位置和门热区固定。

## 2. 五帧内容

| 帧 | 名称 | 画面要求 | 停留 |
|---|---|---|---:|
| F0 | 风前安静 | 草、衣摆、发梢、猫耳、尾巴处于中性姿态 | `0.8-1.0s` |
| F1 | 远草先动 | 远草形成同向斜面；近草、人物和猫暂不被风带走 | `0.50-0.65s` |
| F2 | 近草压低 | 前景草轮廓明显换形，远草回落；人物仍坐稳 | `0.55-0.70s` |
| F3 | 风过人物 | 发梢与衣角形成新完整轮廓；肩背、坐骨和头轴不漂 | `0.60-0.75s` |
| F4 | 风到猫 | 猫耳角度和尾巴弧线明确变化；草有余势，随后回 F0 | `0.70-0.90s` |

## 3. 转场节奏

- 内部风页：使用两张下景 Sprite 固定 `140ms smoothstep` 交叉淡化。开始新淡化前先把当前可见度较高的一页稳定为完整画面，再切向新目标；语义状态立即切到目标帧，不依赖动画完成回调。
- 完整一轮：含停留和淡化约 `3.5-4.2s`。首次进入稳定约 `0.8s` 后播放一次；之后每次安静 `4.5-6.5s` 再出现。
- 点门进屋：门点击在任何风页状态都立即有效；若正在淡化，先锁定当前可见帧并立即执行进入语义，不出现黑屏、白闪、空帧或等待淡化结束。
- 其他用户可见跳转：户外→室内、返回户外、会话纸笺、设置、收尾和分享预览均禁止硬切。具体画法、时长及声音链必须另做可见方案并向用户汇报；本合同不自动授权新的门光、镜头运动、遮罩或额外特效。
- 返回户外：从室内回户外时回到户外安静节点 F0 或减少动态等价态，不重播完整开场，不叠加风声或过时音效。

## 4. 减少动态

- 自动风页换帧、位移、旋转、缩放和视差全部关闭。
- 固定使用一幅“中性但带轻微风向倾向”的静态插画。
- 点花、点天空、点门等反馈只允许 `<=180ms` 亮度或透明度变化。
- 减动状态仍必须能完成点门进屋和室内完整流程。

## 5. 验收停止线

- P0：任何未批准样式漂移；多于或少于五幅风页；上景/门/小屋/人物坐骨/猫落点漂移；点门被风页动画阻塞；出现黑屏或白闪；生成探索图进入正式微信包。
- P1：F0/F2/F4 在手机原速或 25% 缩略图不可辨；风页内部未按固定 `140ms smoothstep` 叠化或出现长重影；减少动态仍有位置/缩放；360/390/430 裁切或触控漂移；预加载导致明显卡顿。
- P2：局部草缘接缝、轻微色差、个别帧节奏不够自然但不影响理解和完成。
