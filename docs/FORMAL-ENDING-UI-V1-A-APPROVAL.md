## 批准范围

- 默认收尾界面使用 `A / 灯下留笺`：明亮暖屋右侧墙面上的窄幅暖纸留笺。
- `largeText=true` 时使用 `B / 桌边暖纸`：底部桌边暖纸托盘，字号保持真实 `120%`，不使用 SHRINK。
- 分享预览与分享失败固定使用 `B / 桌边暖纸`，不受普通字号默认 A 的影响。
- 文案固定为：
  - `水热了。你也先缓一会儿。`
  - `再坐一会儿`
  - `今晚到这里`
  - `这一夜，先放在这里。`
  - `给朋友留一盏灯`
  - `回到夜风里`
  - `有人给你留了一盏灯`
  - `发给朋友`
  - `先不分享`
  - `这次没有发出去。`
  - `再试一次`
  - `留在今晚`
- 动效仅允许透明度/明度变化：默认 `170ms`；减少动态时 transform 为 `0`，fade 为 `0`。
- 每个动作热区不小于 `44x44`，相邻热区边缘不小于 `8px`。
