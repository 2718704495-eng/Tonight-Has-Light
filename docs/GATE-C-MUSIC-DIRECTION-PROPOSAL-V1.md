## 1. 研究结论与边界

- 音乐速度、节奏结构和响度会影响唤醒感；较快速度和清晰节拍更容易提高生理唤醒。本项目据此采用无鼓、低密度、慢变化，但不把研究解释成医疗或情绪改善承诺。来源：[Bernardi 等，Heart 2006](https://pmc.ncbi.nlm.nih.gov/articles/PMC1860846/)。
- 音色、音域、协和度、力度和速度共同影响和平/紧张等感受；本项目据此避免尖锐瞬态、强不协和、突然转调和明显高潮。来源：[音乐情绪参数研究综述](https://pmc.ncbi.nlm.nih.gov/articles/PMC5705548/)、[演奏表达与情绪线索研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3726864/)。
- Cocos Creator 3.8 的 Web 音频首次播放受用户手势策略影响，且部分平台音量控制可能存在差异；所以继续坚持首触后播放，并把手机外放与耳机列为硬验证。来源：[Cocos Creator 3.8 AudioSource](https://docs.cocos.com/creator/3.8/api/en/class/AudioSource)。
- EBU R128 提供 LUFS、响度范围和 True Peak 的一致测量方法；它是测量参考，不直接等于小游戏成品目标响度。最终层级必须用手机外放和耳机实听复核。来源：[EBU R128](https://tech.ebu.ch/publications/r128)。

## 3. 负责人推荐

推荐 **A 无拍夜风垫**。

理由：现有环境风已经获批，A 最不容易把赏景变成“任务开始”或剧情推进；它只在首次触碰后增加很薄的陪伴层，符合“凉快、舒服、先坐一会儿”。B 可读性最强，但提示音风险也最高；C 陪伴感更强，却容易偏沉并削弱户外凉意。

## 4. 原创制作提示词

### A 无拍夜风垫

为竖屏夜风草坡场景创作一段原创、无拍、低密度的背景音乐。环境风先被听见，音乐延后约 0.8 秒进入，并在 3 秒内柔和渐入。使用软合成垫、极轻空气颗粒和偶发温和泛音；无鼓、无明显旋律 hook、无突然转折。整体感觉凉爽、安静、有人一起坐着，但不表达医疗、助眠或疗效。循环 48–64 秒，首尾接缝不可察，音乐始终低于环境风。

### B 稀疏星点音

创作一段原创、极稀疏、隐约 52–58 BPM 的夜空音乐。不要鼓点和歌曲结构；只用柔电钢或温和木质/玻璃质短音，加一层很薄的背景垫。每 8 秒只有 1–2 个可辨音，音域约 G3–D5，和声使用开放、低张力的五声音阶或 add6 色彩。音乐在 2.5–3 秒内渐入，第一秒不抢环境风；不要做成奖励或提示音。

### C 暖低层陪伴

创作一段原创、无拍、极慢的低层陪伴音乐，使用柔软低弦样合成垫、暖噪声和轻微呼吸式音量变化。音域以 C3–A4 为主，避免尖锐高频和低频轰鸣；和声使用 sus2/sus4 或开放和弦，缓慢移动，不做悬疑小调或强烈解决。首触后 3 秒淡入，持续低于环境风，循环 48–64 秒且接缝不可察。
