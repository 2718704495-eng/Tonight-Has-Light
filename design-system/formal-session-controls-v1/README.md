# FORMAL-SESSION-CONTROLS-V1-A 可编辑补充资产

本目录只保存用户于 2026-08-26 批准的 A「右墙留时笺」所需补充矢量资产。纸面、按钮、固定点和短线继续复用 `design-system/formal-ending-ui-v1/` 的已批准资产。

- `selection-ring.svg`：默认 5 分钟及用户所选时长的双墨圈。它不发光、不承担奖励或推荐语义。
- `generate-assets.mjs`：确定性生成 Cocos 使用的透明 PNG，不改变暖屋、角色、猫、晚饭、构图、材质或配色。
- `ASSET-HASHES.sha256`：锁定可编辑源与运行时导出，供资产台账和复验使用。

运行时输出位于 `cocos-project/assets/resources/formal-session-controls-v1/`。
