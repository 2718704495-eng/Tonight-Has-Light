# FORMAL-ENDING-UI-V1-A 可编辑资产

本目录是用户于 2026-08-25 批准的 A「灯下留笺」与 B「桌边暖纸」的人工 SVG 源文件。运行时 PNG 由 `generate-assets.mjs` 确定性生成到 `cocos-project/assets/resources/formal-ending-ui-v1/`。

- `wall-note.svg`：普通字号 A 纸笺。
- `table-paper.svg`：120% 大字、分享与失败状态的 B 暖纸。
- `action-paper.svg`：等权文字动作底。
- `note-peg.svg`：A 纸笺固定点。
- `surface-rule.svg`：正文与等权动作之间的短茶褐纸墨线。

这些资产只表现已经批准的暖纸 UI，不包含暖屋参考图、角色、猫或场景像素。不得用它们压暗房间或增加结算／奖励语义。
