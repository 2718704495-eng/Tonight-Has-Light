# INDOOR-N01-PROTOTYPE-V1

状态：`ALIGNED / DISPOSABLE INTERACTION PROTOTYPE`

这是用户于 2026-08-24 批准的“壶盖轻响”独立浏览器样片。它只验证：明亮暖家里的水壶回应、蒸汽、猫碰杯、杯子扶正、静音等价和减少动态等价。

## 启动

在项目根目录运行：

```bash
npm run preview
```

然后访问：

```text
http://127.0.0.1:4173/prototype/indoor-n01-v1/
```

参数：

- `?sound=0`：初始静音。
- `?reduced=1`：强制减少动态。
- 键盘 `M`：切换样片声音。
- 键盘 `R`：重置样片。

- 壶盖声、蒸汽声和杯子声由 Web Audio 在运行时临时合成，不生成正式音频文件，也不表示正式音效已经获批。

## 交互节奏

1. 初态整屋始终明亮，蒸汽微动，无任务箭头或进度条。
2. 轻触约 `120×112` 逻辑区域：蒸汽升起、壶盖在约 `620ms` 内轻响。
3. 约 `1.18s`：猫轻靠近，倒扣杯微微晃动；用户可轻触杯子提前继续。
4. `4s` 无操作后，人物衣袖靠近，杯子自然扶正。
5. 杯子扶正后约 `1.18s` 出现“水热了。你也先缓一会儿。”
6. 十秒无操作只出现一句“壶里的水，正轻轻响着。”，不强迫操作。

减少动态时禁用位移、旋转和缩放，仅用最长 `180ms` 的透明度交叉淡化呈现蒸汽与杯子状态。
