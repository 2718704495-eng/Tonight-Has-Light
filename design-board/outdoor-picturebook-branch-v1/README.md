## 交互合同

- 草坡稳定约 1.5 秒后，在画中对象旁显示“看看星空／吹吹风／回家”。
- 提示不用卡片、图标、菜单、页码或进度点；热区最小 44×44px，支持键盘焦点。
- 点击天空、草尖／花或暖门进入对应五幅探索分镜；每次点击只翻一幅。
- “看星空”第 5 幅完成转场后先静置 `0.9s`；随后只划过一颗流星 `0.8s`，尾迹淡去 `0.45s`，再静置 `1s`，最后以 `180ms` 显示固定文案和“回家／再坐一会儿”。
- 星空结尾的“回家”直接以既有交叉淡变进入“回家”支线第 1 幅，不闪回草坡；“再坐一会儿”回到草坡。吹吹风末页仍回草坡，回家支线停在明亮暖屋结尾。
- 触碰人物或空白处只显示一次：“天空、草尖和亮着的门，都可以轻轻碰一碰。”
- 普通翻页转场 `300ms`。减少动态关闭流星位移，用一道静态流星痕做单次 `≤180ms` 淡入／淡出；翻页只使用 `150ms` 透明度淡变。
- 入口热区优先级为：暖门 > 天空／草尖与花 > 人物／空白提示；天空和草地范围不重叠，人物提示区不能抢走草地、花或暖门分支。
- 分支单页按等比 `cover` 裁切铺满手机画面，不露出底色边条；主任务已逐页检查三条支线，当前裁切未遮掉人物、猫、关键动作、暖门或明亮暖屋；用户已对同一 R2 可见候选回复“没问题”。
- “120% 大字预览”真实放大画中邀请、分支标题、翻页提示与返回文字，不使用 `SHRINK`。
- 结尾两个选择均为至少 `48px` 高的独立触控区，间距 `12px`；不使用卡片、遮罩、奖励音效、粒子或震屏。
