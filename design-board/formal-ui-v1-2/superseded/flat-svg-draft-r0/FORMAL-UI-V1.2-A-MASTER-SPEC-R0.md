## 1. 批准范围

用户批准的是 V1.2-A 的室内情绪与可见方向：

- 进门后不是黑屋，也不是局部小灯池；房间从第一帧就是为你亮着的。
- 画面语义是“深夜回家，灯还亮着，桌上有一份热饭等你”。
- 户外继续冷静、舒心；室内必须明亮、温暖、暖心。
- 墙、天花、地板、家具、人物、猫、桌面饭菜和角落都要可读。
- 窗外夜空只做冷暖对比和来处提示，不成为室内主光。

批准不等于允许直接把参考 PNG 切进 Cocos。正式角色、猫、饭菜、灯具、壶、窗、家具、中文、Logo、图标和关键互动物仍必须原创分层重绘并登记来源。

## 2. 必须保持

- 构图：成人坐左侧三分之四背面，普通家猫在右侧桌前，低桌和晚饭占中下区域，窗外冷夜在左上到中部。
- 光线：广域暖光覆盖整屋，顶灯负责环境亮度，桌侧实用灯负责饭菜和壶的生活焦点。
- 亮度：角落不黑；只能保留物体固有阴影和木器缝隙，不允许黑角吞掉家具或角色轮廓。
- 材质：水粉纸绘／染色纸层，边缘柔软，有纸纹；禁止塑料感、霓虹、Bloom、纯白灼点。
- 情绪：安静到家感，不加入派对、人群、彩带、庆祝音效或具体关系称呼。
- 角色：成年人不命名、不标注性别或关系；猫保持普通家猫比例，不穿衣、不直立、不拟人。

## 3. 必须重绘或删除

- 参考 PNG 不能作为生产纹理；只做构图、光色、晚饭语义参考。
- 墙上相框不得继承可识别人像或暗示具体关系，正式版改为抽象植物画、空白纸纹或移除。
- 多余灯具不能堆成灯具陈列。正式实现保留两个光源角色：顶灯环境光和桌侧实用灯。
- 人物发型、衣纹、猫轮廓、饭菜形状、壶和桌椅结构必须原创重绘，不按参考图逐像素临摹。
- 不添加生日蛋糕、礼物、彩带、群像、惊喜字幕、任务按钮或奖励光效。

## 4. 色彩与层级

| 角色 | 建议色 | 用途 |
|---|---|---|
| 蜂蜜墙光 | `#F3C777` | 墙面、天花、广域暖光 |
| 暖纸白 | `#F7E3AE` | 灯罩、碗、文字底 |
| 浅木棕 | `#C27A31` | 低桌、窗框、地板 |
| 暖深褐 | `#4E2D1A` | 轮廓、家具缝、可读暗线 |
| 低饱和陶土 | `#B55C34` | 坐垫、布料点缀 |
| V7 深海军蓝 | `#06265F` | 窗外夜色和户外连续性 |

视觉焦点顺序：整屋暖光与晚饭 → 人物和猫 → 冷窗 → 装饰细节。灯泡不得成为唯一刺眼焦点。

## 6. 交互影响

V1.2-A 已确定“家里的灯一直为你亮着”，所以原来的“把一小团暖光拖到壶边”不再适合作为核心因果。下一步应提交玩法替代：

- 推荐核心动作：轻触保温罩／饭碗／壶盖，让热气轻轻起来。
- 保留方向：杯子放反的小剧场可以继续，但由人物或猫的小动作触发，不要让“点亮房间”成为任务奖励。
- 时长选择、收尾、分享、暂停、设置、静音、大字、减少动态继续沿用 D-lite 合同。

## 7. QA 停止线

进入 Cocos 前至少补齐：

- 390×844 正式母版截图和 25% 缩略图。
- 360×800、390×844、430×932 构图检查。
- 低亮检查：四角仍能分辨墙、地板、家具、人物和猫。
- 过曝检查：灯泡、碗、饭和窗外星空无纯白灼点。
- 资产登记：所有正式层有 SHA-256、作者、来源、授权和版本。
