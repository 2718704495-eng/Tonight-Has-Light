03 / 明亮方法

让空间亮，不让屏幕刺眼。

“明亮”由大面积可读的墙面、天花、地板和家具表达，不靠高亮纯白、Bloom 或整屏橙色滤镜。

蜂蜜奶油#F0C66F
暖纸白#F4DFB2
浅木色#C89355
低饱和陶土#B66F4C
窗外冷蓝#173F73
  1. 广域均匀／间接光墙、天花、地板都有中亮层次；角落可以更柔，但不能掉进黑色。
  2. 桌面是内容焦点简单晚饭、饭碗、汤与热壶比装饰更重要，表达“有人替你留了饭”。
  3. 冷蓝只做温差窗外夜色保留来路和纵深，不把蓝光投满整个室内。
  4. 正式稿删除探索残留只留广域环境／间接光与一处桌侧实用灯；删除多余第三灯具，不画可识别人像或具体关系照片。
  5. 亮度安全线纯白灼点 0、Bloom 0、整屏橙滤镜 0；灯具保留罩面和灯芯细节。
