00 / 不变项

室内必须像从这片夜色里长出来。

角色人物左、猫右；三分之四背面；共同材质与受光。
材质明亮柔和的水粉纸绘／染色纸层，不换成毛毡或塑料。

01 / 室内构图 A–B

同一晚，只换空间承接方式。

两张图均为 imagegen 光色／构图探索，不是生产资产，人物、猫、物件与文字仍需原创分层重绘。

方案 A

窗边小桌

负责人推荐

视线顺序稳定为“窗外冷夜 → 人物与猫 → 壶边暖光”，进屋后明显更安定，又没有与户外断开。

优点
核心互动最清楚；360/390/430 更容易保持构图；减动版不依赖镜头。
签名元素
原创木臂纸罩灯，只投下一块可以带到壶边的暖光；它不是角色。
风险
窗外星河需要再降一级，避免和水壶争焦；纸罩灯不可照搬知名灯具。
方案 B

半开门廊

连续感更强

门外仍留一小段夜色，户外到室内不突兀；风像在门口停住，再把注意力交给水壶。

优点
空间关系直观；门转场自然；“凉快”不会进屋后立刻消失。
成本
需要额外门框、前景遮挡与透视切层，资源和适配成本约高 25%–35%。
风险
门容易再次像关卡入口；纵深与外景可能抢过人物和水壶。

03 / 门转场与小剧场

只安排两次“值得动”的时刻。

门转场 · 约 0.9s
  1. 触门后 120ms 内，门光只压亮一次。
  2. 暖色纸边从门内扩张 680ms，填满画面。
  3. 同色灯池交叉显出室内 120ms；不推镜头、不放大人物。
  4. 减少动态：直接用 180ms 交叉淡化。
杯子小剧场 · 约 2.4s
  1. 人物疲惫地把杯子倒扣在桌上。
  2. 猫闻一下杯沿，用前爪轻碰，杯子只晃一次。
  3. 人物停 0.8s，发现后把杯子翻正。
  4. 用户可轻触继续；4 秒无操作自然完成。
声音接力 · 不做奖励音
  1. 触门只给一次很轻的木门／纸灯触感，不用清脆“通关”提示。
  2. 0–0.9s 内把已批准风声柔和收窄，而不是突然截断。
  3. 进屋后交给很低的壶鸣与房间底噪；音乐方向仍单独等待批准。
  4. 静音和系统抢占后不越权自动恢复，画面仍完整表达因果。

04 / 建议一起批准的决策包

减少后面反复改样式。

这些选择现在都只是提案。你批准后才会记录版本与哈希，并分发给 UI、Cocos 和 QA。

室内方向A · 窗边小桌

最容易保持安静层级，也是负责人推荐。

设置入口首次触碰后出现

零操作前 20 秒仍无 UI；用户一旦触碰，左上安全区出现稳定小圆点，否则 20 秒后出现，避开微信右上胶囊。

房间亮度第一版暂不做

先保留音乐、环境声、触碰反馈、减动和大字；避免与手机亮度及暗部验收互相干扰。

后台回来室内先停住

显示“我们停在这里了。”，由用户选择继续或结束今晚；声音不越权自动恢复。

窗雾内容露出稀疏星群

延续户外夜空，不再新增一个抢焦的满月。

字体思源黑体＋思源宋体子集

功能字用黑体；两句叙事用宋体。只裁入实际字符并登记 SIL OFL 许可。
