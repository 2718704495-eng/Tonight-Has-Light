# 《今夜有灯》Gate B 视觉方向对比板

这是一个不需要安装依赖或执行构建的静态设计交付物。

## 查看

直接用浏览器打开 `index.html`。页面包含：

- 三套严格保持同一角色、房间构图和首夜情节的 390 × 844 首页母版；
- 每套方案的 48px 可辨识角色剪影、色票、系统字体、材质和光线脚本；
- 每套方案各六帧动效故事板；
- 按既定权重完成的评分表，默认选择“月光灯箱”。

## 设计边界

- 所有视觉均由本地 HTML、CSS 和 SVG 确定性绘制；
- 不引用外部图片、远程字体、现成角色或第三方 IP；
- 软团兽和灯灵共享同一套 SVG 轮廓，三个方向只改变色彩与材质语言；
- 页面支持窄屏横向检查，并响应系统“减少动态”设置。

## 文件

- `index.html`：设计板结构、三套母版、故事板与评分内容；
- `styles.css`：全部视觉、角色着色、材质、动效和响应式规则。
