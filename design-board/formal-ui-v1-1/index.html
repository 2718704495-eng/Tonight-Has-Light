03 / 光线合同

下列比例是正式原创重绘的目标分区，不声称探索图已经完成像素级测量。

  1. 第一焦点纸灯／壶边暖光亮但不白，保留纸罩纹理、壶身暗面与蒸汽层次。

05 / 0.9 秒转场

光先照到物，才照到人。

动效只解释空间和光源，不制造奖励感，也不借镜头推进强迫用户进屋。

  1. 0–120ms门光回应只压亮一次，确认“我碰到了”，门本身不脉冲。
  2. 120–680ms暖纸层掠过染色纸边从门内横过，保留纸绘颗粒，不用白闪。
  3. 680–820ms壶和桌先亮室内灯池先显出纸罩、壶边、桌面纹理和蒸汽。
  4. 820–900ms暖边落到肩背人物肩背、发梢与猫耳背最后接到薄暖边，完成“被接住”。
默认不推镜头 · 不放大角色 · 不整屏闪白 减少动态关闭掠过与位移，仅用 180ms 交叉淡化到同一中性终态

06 / 保持不变

这次只改“屋里的温度”。

下列规则继续锁定；任何正式资产和运行时变化都必须在用户批准 V1.1 后另行制作和复验。

材质水粉纸绘／染色纸层

场景、人物、猫、物件使用同一颗粒、边缘和冷暖受光。

角色正常成年人＋普通家猫

人物左、猫右；不幼龄化、不拟人化、不命名，不借现成 IP 轮廓。

适配SafeArea＋44×44

360/390/430 保持关键物完整；相邻热区至少 8px。

大字真实 120%

功能字不靠 SHRINK 塞回固定容器，叙事短句可自然换行。

减动静态因果等价

关闭位移、视差与掠过后，仍能看懂从门到灯、从壶到人的层级。

资产探索图不入包

正式角色、灯、壶、图标和中文必须可编辑、可追溯、原创重绘。
