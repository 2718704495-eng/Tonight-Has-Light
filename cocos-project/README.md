# 今夜有灯 · Cocos 历史室内 V0

> **停止线：** 当前正式入口已改为“星河穹顶夜风草坡→用户主动点门→室内第一夜”。本目录现有 `TonightHasLightV0View` 是旧室内 Graphics 可见切片，只能用于领域逻辑、存档、声音和生命周期回归；不能作为当前户外 Gate B/C 证据，也不能继续扩展为正式视觉层。正式实现必须等待用户批准的 390×844 户外母版，并改用持久 Scene/Prefab/Sprite/Atlas。

这是 Cocos Creator 3.8.8 + TypeScript 的微信小游戏底层工程与历史室内回归起点，包含：

- 可直接运行的 390×844“月光灯箱”第一夜可见切片，完整覆盖时长选择、首次触碰、拖光/点壶、扶杯小剧场与收尾；
- 项目原创 24 秒环境声候选、首次触碰后 2.5 秒渐入、静音与前后台暂停恢复；
- 声/静、减少动态与大字入口，所有触控目标不小于 44px；
- 五夜线性内容定义与 3/5/8 分钟模式；
- 无失败的夜间状态机、核心/环境互动与收尾语义；
- `LocalSaveV1`、`UserSettings`、`AssetRecord` 以及损坏存档恢复；
- 微信前后台安全节点恢复与固定分享入口；
- 第二至第五夜的 Asset Bundle 小游戏分包配置；
- 无需安装 npm 依赖的 Node 24 回归测试。

首次编辑器接线见 [docs/EDITOR_SETUP.md](docs/EDITOR_SETUP.md)。

```bash
npm run verify
```
